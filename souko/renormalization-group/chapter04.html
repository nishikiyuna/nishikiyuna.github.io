4-1 φ⁴場の量子論と発散の困難

原著 印刷pp.95–98 / 提供PDF pp.105–108

Euclid場の相関関数をSchwinger関数と呼ぶ。最初に格子間隔aを導入すれば、運動量はおおよそπ/aまでに制限される。有限切断で定義した相関関数から出発し、a → 0で有限な物理量が残るように裸のパラメタを選ぶ。発散積分へ形式的に有限値を与えることだけが目標ではない。

\[\Lambda _{\mathrm{UV}} \sim \pi /a,\text{　} \xi _{\mathrm{latt}} = \xi _{\mathrm{phys}}/a \to \infty \]
なぜ格子間隔をゼロにすると発散が現れるか
\[\delta m^2\sim\lambda\int^{\Lambda}\frac{d^4k}{(2\pi)^4}\frac1{k^2+m^2}\sim\lambda\Lambda^2,\qquad \Lambda\sim a^{-1}.\]

高い運動量の寄与は、低い運動量で見たときには質量項などの局所係数を変える。\(a\to0\)で裸の質量を固定したままでは、物理的な質量も固定されない。切断依存の大きな補正を裸の量へ取り込み、観測に対応する有限な量を一定にする必要がある。

自由場でも場を格子から連続体へ移すときは次元を合わせる。格子変数を無次元に選ぶなら、連続体の場は概ね\(a^{-(d-2)/2}\)倍の大きさを持つ。相互作用により、この単純な次元へさらに場の規格化が加わる。

4-2 くりこみ理論

原著 印刷pp.98–100 / 提供PDF pp.108–110

\[\Gamma ^{(2)}_{R}(0) = m_{R}^{2},\text{　} \partial \Gamma ^{(2)}_{R}/\partial p^{2}|_{p=0} = 1\]
\[\Gamma ^{(4)}_{R}(0,0,0,0) = \lambda _{R}\]

ここでは有質量Euclid理論の例として零運動量の規約を示した。質量、場の規格化、四点相互作用を固定し、切断が変わっても同じ条件を満たすよう裸の質量や結合を調整する。零質量の理論では赤外特異性を避けた非例外的運動量など、別の条件が必要になる。

くりこみ条件は独立なデータを固定する

二点関数の値だけを指定しても、場の全体的な倍率は決まらない。逆伝搬関数の運動量微分を指定する条件がその規格化を決める。四点関数の条件は、質量と場の倍率だけでは決まらない相互作用の強さを指定する。

\[\Gamma_R^{(2)}(p)=m_R^2+p^2+O(p^4),\qquad \Gamma_R^{(4)}(\{p_i\})=\lambda_R+O(p_i^2).\]

この表示は有質量で原点近傍の展開が使える例である。別の運動量で条件を置いてもよいが、異なる条件で得た\(m_R,\lambda_R\)を同じ数値のまま比較してはいけない。条件間の有限な変換を含めて、同じ物理理論かどうかを判断する。

4-3 くりこみ群と連続極限

原著 印刷pp.100–107 / 提供PDF pp.110–117

粗視化を一回行っても同じ低エネルギー理論になるよう、より細かな格子の理論を用意する。これを任意回繰り返せれば、微視的切断を上げる系列が作れる。固定点から湧き出るくりこまれた軌道が、そのような系列を指定する。

格子間隔を小さく裸の量を調整同じ物理を維持

固定点へ近づく有効方向の数は、連続極限を指定する独立な物理パラメタの数と関係する。ただし、粗視化の逆が全理論空間で存在するわけではない。必要なのは特別に選ばれた軌道に沿った構成であり、その存在が本質的な問題である。

読み方・注意

臨界現象と連続極限の共通点：どちらも格子単位での相関距離が無限大になる。ただし連続極限では物理的な長さを固定し、長さの単位そのものを変える。

連続極限をRG軌道として読む

\(a_n=b^{-n}a_0\)の格子系列を取り、\(S_{-n}\)を\(n\)回粗視化すると\(S_0\)になるように選ぶ。

\[R_b^n S_{-n}=S_0,\qquad a_n\xi_{\mathrm{latt},n}=\xi_{\mathrm{phys}}.\]

\(S_{-n}\)の系列は、短距離へさかのぼったとき固定点へ近づく特別な軌道である。臨界面へ向かう誤差を調整することで、全ての有限の物理距離で相関関数の極限を得ることを目指す。

\[G_R^{(n)}(x_1,\ldots,x_n)=\lim_{a\to0}Z(a)^{-n/2}G_a^{(n)}(x_1,\ldots,x_n).\]

ここでは\(G_a\)を既に物理座標・場の古典的な次元へ換算したものとした。極限の存在、点が一致するときの特異性、許される試験関数の範囲などは、構成の中で別途示す必要がある。

4-4 連続極限の例

原著 印刷pp.107–113 / 提供PDF pp.117–123

例短距離での振舞い原著の議論の位置づけ
自由場Gaussian点質量方向だけを動かす基準例
d = 3のφ⁴理論無次元の相互作用は短距離で小さい超くりこみ可能。相互作用を残せる
d = 4−εの固定点からの軌道Wilson–Fisher点異常次元を持つ連続極限の考察
d ≥ 4のφ⁴理論紫外への延長が問題になる自明性と有限切断の制約を検討

3次元φ⁴の結合λは質量次元1を持つ。無次元のλ/μが高運動量で小さくなっても、次元を持つ相互作用λ_Rが消えるとは限らない。この点は、4次元の無次元結合がゼロになることと区別する必要がある。

d = 4−εの固定点から出る軌道は、Gaussian理論とは異なる場の次元を与える。非整数次元での考察は流れの構造を理解するための理論的な例であり、そのまま整数次元の相対論的場の構成を証明するものではない。

例：3次元と4次元の結合の違い
\[[\lambda]=\text{mass}^{4-d},\qquad g(Q)=\lambda(Q)Q^{d-4}.\]

\(d=3\)で次元を持つ\(\lambda\)がほぼ一定なら、\(g(Q)\sim\lambda/Q\to0\)。相互作用を持つ低エネルギー理論と、Gaussian型の短距離極限は両立する。\(d=4\)では\(\lambda\)自体が無次元であり、その走りは量子補正で決まる。

\[\frac1{\lambda_R(\mu)}\simeq\frac1{\lambda_{\mathrm{bare}}(\Lambda)}+\frac3{16\pi^2}\log\frac\Lambda\mu.\]

4次元・正の弱結合という仮定の下では、切断を大きくすると低エネルギー結合に制約が生じる。この式は有限切断の有効理論の見通しを与えるが、弱結合近似の式だけを自明性の非摂動的証明として使わない。

4-5 構成的場の量子論

原著 印刷pp.113–114 / 提供PDF pp.123–124

相関関数が有限になるだけでは十分でない。極限で得たSchwinger関数がEuclid場の公理に従い、適切な条件の下でMinkowski時空の量子論へ再構成できることを確かめる。摂動展開の各次数が有限であることと、理論そのものの存在とは異なる主張である。

\[\text{有限切断の定義} \to \text{パラメタ調整} \to \text{極限の存在} \to \text{量子論の再構成}\]

原著は、格子正則化したd > 4のφ⁴理論の自明性を厳密な結果として挙げ、d = 4については当時の予想・未解決問題として論じている。ここでは、その記述を刊行時点の議論として読む。有限切断の理論では、切断の高さと低エネルギーで許される結合の大きさが関連する。

読み方・注意

区別：摂動的にくりこみ可能／非自明な連続極限が存在／相関関数の公理が成立。これらを同じ意味で用いない。

Euclid場の再構成に必要な性質

Euclid相関関数には、適切な対称性・正則性・Euclid変換に対する共変性などに加え、反射正値性が重要となる。これは時間を反転した側との相関から非負の内積を作る条件であり、Hilbert空間と正のエネルギーを持つ量子論へつなぐ。

\[\sum_{i,j}\overline{c_i}c_j\,\langle (\Theta F_i)F_j\rangle\ge0.\]

\(F_i\)を正のEuclid時間に台を持つ場の関数、\(\Theta\)を時間反射と複素共役を組み合わせた操作とする。これは条件の骨格を示す式であり、相関関数の分布としての定義や他の公理も必要である。

全ての摂動係数を計算できても、その形式級数がこのような相関関数を定めるとは限らない。第7章のBorel総和と部分くりこみは、この間隙を埋める具体例として位置づけられる。
