AI 密度行列による状態の選択

原著 印刷pp.229–231 / 提供PDF pp.239–241

環境を含んだ状態から縮約密度行列を作る

量子多体系ではHilbert空間の次元がサイト数とともに急増する。小さなブロックのハミルトニアンだけを対角化して状態を残すと、周囲との相関に重要な状態を捨てることがある。DMRGでは、系と環境からなる全体の対象状態を先に求め、その部分トレースを用いる。

\[|\Psi \rangle = \sum _{ij} C_{ij}|i\rangle _{L}|j\rangle _{R},\text{　} \rho _{L} = \operatorname{Tr} _{R}|\Psi \rangle \langle \Psi |\]
\[(\rho _{L})_{ii'} = \sum _{j} C_{ij}C*_{i'j}\]

大きい固有値の状態を残す

\[\rho _{L}|\alpha \rangle = w_{\alpha }|\alpha \rangle ,\text{　} w_{1} \ge w_{2} \ge \cdots \ge 0,\text{　} \sum _{\alpha }w_{\alpha } = 1\]

大きい固有値からm個の固有ベクトルを選ぶ。列にそのベクトルを並べた等長写像Uを使えば、残す空間のハミルトニアンはH_eff = U†HUとなる。境界の相互作用や観測演算子も同じ基底へ変換して保持する。

\[\varepsilon _{\mathrm{disc}} = \sum _{\alpha >m}w_{\alpha }\]

ε_discはこの状態を射影した際の捨てられた重みである。固定された対象状態に対し、密度行列の大きい固有値を残す選択は、そのm次元部分空間への射影の損失を最小にする。ただし、捨て重みがそのまま全観測量の誤差や基底エネルギーの誤差に等しいわけではない。

Wilson型RGとの関係と違い

共通するのは自由度を減らして有効記述を作る点。中心となる判断基準は異なり、臨界RGは全尺度の揺らぎと固定点、DMRGは対象状態をよく表す部分空間の選択を重視する。原著は、特に一次元のギャップを持つ量子系に適した数値手法として紹介している。

読み方・注意

原著の補章IとIIはDMRGと「くりこみ群」の関係に異なる強調を置く。用語の一致だけで同じ理論構造とみなさず、残す情報と目的を比較するとよい。

導出：密度行列の固有値を大きい順に残す理由

\(C\)を特異値分解すると、全系の純粋状態はSchmidt形になる。これは縮約密度行列の選択を説明するための補足的な表現である。

\[|\Psi\rangle=\sum_\alpha\sqrt{w_\alpha}\,|\alpha\rangle_L|\alpha\rangle_R.\]

左部分系の任意の階数\(m\)の直交射影\(P_m\)に対し、残るノルム二乗は\(\operatorname{Tr}(P_m\rho_L)\)。これを最大にするのは最大の\(m\)個の固有値の空間である。

\[\max_{\operatorname{rank}P_m=m}\operatorname{Tr}(P_m\rho_L)=\sum_{\alpha=1}^m w_\alpha.\]

固有値が速く減る状態では少数の基底でよい近似が可能になる。固有値が広く分布する場合は、同じ\(m\)では捨て重みが大きい。実際の反復では環境や対象状態も近似されるため、この最適性は一度固定した\(\rho_L\)に対する主張である。

何を同時に変換するか

有効ハミルトニアンだけでなく、次のサイトと相互作用する境界演算子も\(U^\dagger O U\)へ変換する。これを保持しなければ、新しいブロックを成長させたとき元の模型の結合を再現できない。DMRGも「残す情報」を具体的に設計する方法である。
