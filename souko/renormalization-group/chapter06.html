6-1 運動量空間の階層化

原著 印刷pp.173–176 / 提供PDF pp.183–186

Pauli–Villars型の切断を分解する

原著ではEuclid伝搬関数に滑らかな正則化因子を導入し、その差を用いて運動量空間を階層化する。以下は同じ仕組みを示す簡略な分解であり、原著の正則化因子そのものではない。M > 1とし、ρ_h(p) = exp[−p²/(m²M^(2h))]を用いる。

\[C^{\le H}(p) = \rho _{H}(p)/(p^{2}+m^{2}) = \sum _{h=0}^{H} C_{h}(p)\]
\[C_{0}(p) = \rho _{0}(p)/(p^{2}+m^{2})\]
\[C_{h}(p) = [\rho _{h}(p)-\rho _{h-1}(p)]/(p^{2}+m^{2})\]

hが大きいほど主に高い運動量を扱う。各C_hは厳密な球殻上だけに台を持つ必要はなく、対応する尺度の外で十分に抑えられればよい。このようにして、全伝搬関数を尺度ごとの和として書く。

内線の指数配置

\[A_{G} = \sum _{h: \text{内線}\to \text{尺度番号}} A_{G,h}\]

グラフGの各内線へ尺度番号を与えたものを指数配置と呼ぶ。どの部分グラフの内部運動量が、その外側の運動量より大きいかが明示される。これにより、局所項として取り込むべき高エネルギー部分を、具体的な配置ごとに選べる。

読み方・注意

相空間展開はグラフのトポロジーだけでなく、流れる運動量の大小関係まで保った展開である。第3章の多スケール分解を、摂動グラフの上で実装する道具と読める。

望遠和としての尺度分解
\[\sum_{h=1}^{H}(\rho_h-\rho_{h-1})=\rho_H-\rho_0.\]

したがって低運動量の\(C_0\)を加えれば、切断付き伝搬関数を正確に再現する。分解の詳細は自由に選べる部分があるが、各帯での減衰と微分の評価が後の引算に適していなければならない。

\[|p|\sim m M^h\quad\Longleftrightarrow\quad |x|\sim (m M^h)^{-1}.\]

高い運動量の帯ほど位置空間では短い範囲の効果となる。この短距離性により、その外側の低い運動量に対してTaylor展開し、局所的な結合へ吸収することが可能になる。原著のPauli–Villars型分解では、大きな有効質量を持つ伝搬関数の差がこの役割を果たす。

6-2 くりこみ部分グラフの森

原著 印刷pp.176–177 / 提供PDF pp.186–187

\[\omega (G) = dL - 2I\text{　　}(\text{微分頂点を持たないスカラー理論})\]

Lは独立ループ運動量の数、Iは内線の数。4次元のφ⁴グラフでは、真空項を除くとω = 4−Eとなり、外線数E = 2、4のグラフが局所的な発散を持ち得る。ただし、全体のωだけを見ても内部の細分発散は分からない。Fermi伝搬関数では大運動量での減衰次数が異なる。

森は、発散型の部分グラフのうち、任意の二つが互いに離れているか、一方が他方に含まれる集合である。交差する二つは同じ森へ入れない。空集合も森に含め、グラフ全体が発散型ならG自体を含む森も考える。

計算：スカラーφ⁴理論の表面発散次数
\[4V=2I+E,\qquad L=I-V+1.\]

連結グラフについてこの二式を\(\omega=dL-2I\)に代入する。4次元では

\[\omega=4-E.\]

二点グラフは二次まで、四点グラフは零次の局所引算が必要となり得る。六点以上は全体として表面収束でも、内部に二点・四点の発散部分を含む可能性がある。従って外線数だけで全グラフの収束を判断してはいけない。

「森」の条件は、交差する部分を同時に縮約することの曖昧さを避ける。互いに離れた部分は独立に処理でき、入れ子なら順序を指定できる。交差部分は別々の森の和の中で扱う。

6-3 森公式

原著 印刷pp.177–181 / 提供PDF pp.187–191

\[R A_{G} = \sum _{F: forest} [\prod _{\gamma \in F}(-T_{\gamma })] A_{G}\]

T_γは部分グラフγの外部運動量について、発散次数までTaylor展開する局所引算演算子。入れ子の演算子は内側から適用する。この表示では全体引算も森の和へ含めている。全体を除いた「準森」を使う規約では、全体の(1−T_G)を別に掛ける。

部分グラフの関係同じ森に入るか演算の整理
互いに離れている入る独立な引算
入れ子入る内側を処理して外側へ
交差する入らない異なる森の項として合算

細分発散を持たない対数発散グラフなら、森は空集合と{G}だけで、R A_G = (1−T_G)A_Gとなる。一方、複数の発散部分へ思いつくまま引算を掛けると、重複や取り残しが起こる。森公式はその組合せを一義的に定める。

読み方・注意

Taylor引算の基準点に赤外の問題がないことも必要。有質量の議論と零質量の議論を、同じ零運動量引算で無条件に扱わない。

森公式の小さな例

全体\(G\)が発散し、互いに離れた二つの発散部分\(\gamma_1,\gamma_2\)だけを持つとする。このとき準森は\(\varnothing,\{\gamma_1\},\{\gamma_2\},\{\gamma_1,\gamma_2\}\)。全体の引算を別に書けば、

\[R A_G=(1-T_G)(1-T_{\gamma_1})(1-T_{\gamma_2})A_G.\]

もし\(\gamma_1\)と\(\gamma_2\)が交差するなら、最後の積の項を同じ森として入れることはできない。この例で他の発散部分がなければ、準森の和は\(1-T_{\gamma_1}-T_{\gamma_2}\)となる。実際には二つを含むより大きい発散部分も調べる必要がある。

Taylor引算後に「全体の運動量が大きいとき」と「部分だけが大きいとき」の双方で改善が起きることを評価する。森公式はその改善を得るための組合せであり、積分の収束証明には解析的な評価も要る。

6-4 森の分類

原著 印刷pp.181–183 / 提供PDF pp.191–193

\[i_{\gamma } = \min (\text{内部の尺度番号}),\text{　} e_{\gamma } = \max (\text{外部の尺度番号})\]

最も簡単な場合、i_γ > e_γなら内部がすべて外部より高運動量であり、γを危険な部分と呼ぶ。外部運動量でのTaylor展開が局所的な高エネルギー効果を取り出す。原著では既存の森の最大内被覆・最小外被覆も考慮して、この比較を一般化する。

森に依存する内部・外部の比較

森\(F\)の中で\(\gamma\)に真に含まれる部分の和を\(A_F(\gamma)\)、\(\gamma\)を真に含む最小の部分を\(B_F(\gamma)\)とする。該当する部分がない場合の約束は原著の定義に従う。

\[i_\gamma(F)=\min_{l\in\gamma\setminus A_F(\gamma)}h_l,\qquad e_\gamma(F)=\max_{l\in E(\gamma)\cap B_F(\gamma)}h_l.\]

入れ子の内部を既に別の部分として処理しているため、単純に全ての内部線の最小値を見るのではなく、被覆を除いて比較する。\(i_\gamma(F)>e_\gamma(F)\)が危険、逆の不等式が安全である。

森を大きくすると内部の最小値は上がり得て、外部の最大値は下がり得る。そのため危険な部分の集合は増える方向、安全な部分は減る方向に動く。この単調性が次の二つの補題に使われる。

6-5 森公式の相空間展開

原著 印刷pp.183–186 / 提供PDF pp.193–196

指数配置を固定すると、森を安全な部分と、それに整合する危険な部分へ分類できる。安全な森への射影と、その像を持つ森族の特徴づけが組合せ論の核となる。危険部分をまとめて(1−T_γ)の積にすると、尺度差による収束改善を直接評価しやすくなる。

安全な森を固定した再編

\(S_h(F)\)を\(F\)の安全部分、\(H_h(F_s)\)を安全な森\(F_s\)に整合する危険な部分グラフの集合と書く。原著の補題により、

\[S_h(F)=F_s\quad\Longleftrightarrow\quad F_s\subseteq F\subseteq F_s\cup H_h(F_s).\]

右辺は、危険な部分の中から任意の部分集合を選んで加えることを意味する。この部分集合について\(-T_\gamma\)の積を和にすると、\(\prod_{\gamma\in H_h(F_s)}(1-T_\gamma)\)になる。

\[R A_G=\sum_h\sum_{F_s}\left[\prod_{\gamma\in F_s}(-T_\gamma)\right]\left[\prod_{\gamma\in H_h(F_s)}(1-T_\gamma)\right]A_{G,h}.\]

これは全体引算を含む森の規約で書いた模式的な形であり、入れ子の演算順序を保つ。危険な高運動量部分に\((1-T)\)が掛かる構造が表に出るため、尺度差による収束改善を直接取り出しやすくなる。

6-6 補題の証明

原著 印刷pp.186–195 / 提供PDF pp.196–205

本節は、森の分類が単なる直観ではなく正確な再編であることを示す組合せ論の部分である。原著は補題6-1の内部指数・外部指数の不変性、補題6-2の危険部分の整合性と森族の特徴づけを順に証明する。以下はその論理の要約であり、全ての線の所属関係の確認は原著の証明を参照する。

補題6-1の要点
\[i_\gamma(F)=i_\gamma(S_h(F)),\qquad e_\gamma(F)=e_\gamma(S_h(F)).\]

被覆を安全な部分だけへ制限しても、指数の最小値と最大値が変わらない。従って、安全部分をもう一度取り出しても変化しない。

\[S_h(S_h(F))=S_h(F).\]
証明の筋道：危険部分の入れ子をたどる

安全な内被覆へ置き換えると、最小値をとる候補の線が増える。一見すると最小値が下がりそうだが、新しく加わった線が危険部分の内部にあるなら、その部分の外部線にはさらに小さい指数がある。危険部分の入れ子を外へたどると、元から候補に含まれていた線へ行き着く。従って新しい線が最小値を下げることはない。

外部の最大値にも逆向きの比較を行う。被覆と森の整合性によって、追加された候補の指数を元の候補以下に抑えられることを示す。ここで「互いに離れるか入れ子」という森の条件が決定的になる。

補題6-2の要点

安全な森に整合する危険部分は、互いに交差せず森になる。もし二つが交差すると、一方の内部で他方の外部にある線と、その逆の線を選べる。両方が危険であることから、二本の指数に互いに逆の厳密不等式が出て矛盾する。

その上で、安全部分が\(F_s\)に一致する森が、ちょうど\(F_s\)と\(F_s\cup H_h(F_s)\)の間にあることを両方向に証明する。これにより前節の和は漏れも二重計数もない。

6-7 部分くりこみと有効結合定数

原著 印刷pp.195–201 / 提供PDF pp.205–211

\[g_{h-1} = g_{h} + \delta g_{h},\text{　} m_{h-1} = m_{h} + \delta m_{h}\]

高運動量の寄与から局所的な質量項・場の規格化・頂点を取り出し、次の低い尺度の係数へ吸収する。残りには外部運動量と内部運動量の比による小ささが残る。この処理を反復すると、異なる尺度の有効結合が混じる部分くりこみ級数になる。

\[\text{単一の結合で全てを展開} \to {g_{h}}\text{を保った尺度別の展開}\]

くりこみで消えるべき高エネルギー効果を、最初から尺度に応じた結合で表現する。単一の結合へ無理に再展開して生じる大きな対数や相殺を、流れの中へ組み込むのである。ただし部分くりこみを定義しただけで一般の模型の収束が保証されるわけではない。

読み方・注意

第6章の結論：発散を除くアルゴリズムを、スケールごとの有効理論を作るアルゴリズムとして読み直せる。

なぜTaylor残余が尺度差を稼ぐか

内部運動量が\(M^i\)、外部運動量が\(M^e\)、\(i>e\)とする。発散次数\(\omega\)までTaylor引算を行うと、残りは外部運動量の\(\omega+1\)次から始まる。十分な滑らかさがある場合、模式的には

\[(1-T^\omega)A(p_{\mathrm{ext}})\sim\left(\frac{M^e}{M^i}\right)^{\omega+1}\times\text{内部尺度での大きさ}.\]

この比が小さいことが高運動量部分を局所項へ分離する根拠である。取り出した局所項は次の尺度の質量・結合・場の規格化へ吸収し、残余には減衰を残す。

部分くりこみは、全ての項を単一結合のべきに展開し直す前に、この尺度依存を保持する。どの頂点がどの有効結合を持つかを指数配置から定めるため、高次の計算でも局所な更新の構造が保たれる。
