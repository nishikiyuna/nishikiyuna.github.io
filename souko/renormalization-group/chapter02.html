2-1 臨界現象とスケール不変性

原著 印刷pp.12–21 / 提供PDF pp.22–31

強磁性体では、整列を促す相互作用と熱揺らぎが競合する。自発磁化は、熱力学的極限をとってから外場をゼロへ近づけて定義する。有限系の対称なGibbs状態の磁化がゼロでも、自発的対称性の破れを否定することにはならない。

\[f_{L}(m) = r m^{2}/2 + u m^{4}/4 - h m,\text{　} u > 0\]
\[h = r m + u m^{3}\]

rが温度差tに比例するとすれば、h = 0、r < 0で |m| = √(−r/u)。r > 0の線形応答はχ = 1/r、r = 0ではmがh^(1/3)に比例する。したがって平均場ではβ_mag = 1/2、γ = 1、δ = 3となる。勾配項を入れたGaussian近似はν = 1/2、η = 0を与える。

導出：平均場の自己無撞着式からLandau形へ

各スピンを\(s_i=\pm1\)、配位数を\(z\)とする。隣接スピンを平均磁化\(m\)で置き換えると、一つのスピンが感じる無次元場は\(zKm+h\)となる。

\[m=\tanh(zKm+h).\]

\(\tanh x=x-x^3/3+\cdots\)を使うと、\(zK=1\)の近くで\(h\)は\(tm\)と\(m^3\)の和で表される。これはLandau自由エネルギーを微分した状態方程式に一致する。平均場は相互作用の効果を平均磁化だけへ集約するため、長波長の揺らぎの相互作用を十分には含まない。

\[\langle(\delta m)^2\rangle_{\xi}\sim\xi^{2-d},\qquad m_0^2\sim |t|,\qquad \xi\sim |t|^{-1/2}.\]

従って、相関体積で平均した揺らぎと平均場の秩序変数の二乗の比は、定数因子を除いて\(|t|^{(d-4)/2}\)の形になる。この見積りがGinzburgの判断基準の骨格であり、\(d<4\)で臨界点に近づくほど平均場近似が危うくなる理由を示す。

2-2 粗視化とくりこみ群

原著 印刷pp.21–29 / 提供PDF pp.31–39

\[\exp (-S'[\Phi ]) = \int D\varphi P[\Phi ,\varphi ] \exp (-S[\varphi ])\]

Φはブロック変数、Pは微視的配置をブロック変数に対応させる規格化された重みである。この定義は分配関数を保つ。ブロック内の揺らぎを取り込んだ後に長さの単位と場を再調整し、同じ格子間隔で理論を比較する。

微視的な自由度一部を積分長さと場を再調整

粗視化は一般に新しい相互作用を作る。最近接二体相互作用だけで出発しても、遠距離相互作用や多体項を含む理論空間が必要になる。少数の結合だけで閉じると仮定することは近似であり、後でその誤差を評価しなければならない。

読み方・注意

RGを厳密な群と呼ぶのは一般には正確でない。自由度を捨てる粗視化には通常逆変換がなく、合成則を備えた半群として理解する。

規格化された粗視化核
\[\int D\Phi\,P[\Phi,\varphi]=1\quad\Longrightarrow\quad Z=\int D\Phi\,e^{-S'[\Phi]}.\]

この条件が分配関数を保つための鍵である。観測量も新しい変数で表し直す必要があり、分配関数が等しいからといって、古い局所演算子をそのまま新しい局所演算子へ置き換えてよいわけではない。

\[\langle O\rangle=\frac1Z\int D\Phi\,O_{\mathrm{eff}}[\Phi]e^{-S'[\Phi]}.\]

\(O_{\mathrm{eff}}\)は、\(\Phi\)を固定して消す自由度を平均した量である。相関関数、磁化率、エネルギーなどを比較する際には、ハミルトニアンの変換と演算子の変換の両方を追う。

定数項も情報を持つ

\(S'\)に場によらない定数が生じると、正規化した期待値の多くでは打ち消されるが、自由エネルギーには寄与する。比熱のように自由エネルギーを微分する量を調べる場合は、この定数を捨てたまま計算を終えてはいけない。

2-3 臨界現象におけるくりこみ群

原著 印刷pp.29–34 / 提供PDF pp.39–44

\[R_{b}S* = S*,\text{　　}u'_{i} = b^{yi} u_{i} + O(u^{2})\]

u_iは固定点まわりの固有摂動の係数である。y_i > 0なら長距離で増える有効（relevant）摂動、y_i < 0なら減る非有効（irrelevant）摂動、y_i = 0なら中立的（marginal）摂動となる。中立方向では非線形項を調べる必要がある。

\[f_{s}(t,h) = b^{-d} f_{s}(b^{yt}t, b^{yh}h)\]

f_sは自由エネルギー密度の特異部分。臨界面上では有効方向を調整して固定点へ近づける。非有効な微視的差異が減衰するため、同じ対称性・次元・相互作用の性質を持つ模型に同じ指数が現れ得る。ただし普遍性の範囲は、固定点の吸引域を確認して初めて定まる。

導出：自由エネルギーから指数関係を得る

特異自由エネルギーの同次式で\(b=|t|^{-1/y_t}\)と置く。

\[f_s(t,h)=|t|^{d/y_t}\,\mathcal F_\pm(h|t|^{-y_h/y_t}).\]
\[m=-\partial_h f_s\sim |t|^{(d-y_h)/y_t},\qquad \chi=-\partial_h^2 f_s\sim |t|^{(d-2y_h)/y_t}.\]

したがって\(\beta_{\mathrm{mag}}=(d-y_h)/y_t\)、\(\gamma=(2y_h-d)/y_t\)。\(t=0\)で\(b=|h|^{-1/y_h}\)を選べば\(\delta=y_h/(d-y_h)\)も得られる。式の成立には、自由エネルギーの特異部分がこの二変数で通常のスケーリングをするという条件がある。

\[\alpha+2\beta_{\mathrm{mag}}+\gamma=2,\qquad \gamma=\beta_{\mathrm{mag}}(\delta-1).\]
中立は「変わらない」の最終結論ではない

線形項がゼロでも\(du/d\ell=-Au^2\)なら、\(A>0\)で正の\(u\)はゆっくり減る。解は\(u(\ell)=u_0/(1+Au_0\ell)\)。この対数的な遅さが、4次元φ⁴模型の臨界現象で重要になる。

2-4 補遺：1次元Ising模型のくりこみ群

原著 印刷pp.34–38 / 提供PDF pp.44–48

無次元結合K = J/(k_B T)、零外場の強磁性鎖を考える。奇数サイトのスピンを和で消すと、残るスピンも最近接Ising模型になる。定数因子は自由エネルギーを変えるので別途保持する。

\[\sum _{\sigma =\pm 1} \exp [K\sigma (s+t)] = A \exp (K'st)\]
\[K' = \tfrac12 \log \cosh (2K),\text{　　}\tanh K' = (\tanh K)^{2}\]

有限のK > 0ではK′ < Kであり、繰返すと高温固定点K = 0へ向かう。一方、K = ∞は零温度固定点となる。熱力学的極限で、有限温度に相転移は存在しない。

\[\xi = -1/\log (\tanh K),\text{　　}\xi ' = \xi /2\]

低温ではξ ≃ exp(2K)/2。外場を含む厳密解では m = sinh h / √(sinh²h + exp(−4K)) となり、hとexp(−2K)が同程度の極限にスケーリング形が現れる。

読み方・注意

確認：くりこみ変換を一回計算できることと、無限回の反復を制御できることは別の問題である。

計算例：偶数サイトを残す一段の間引き

両端スピン\(s,t\)が等しい場合、消すスピンの和は\(2\cosh2K\)。反対向きなら2となる。

\[Ae^{K'}=2\cosh2K,\qquad Ae^{-K'}=2.\]
\[K'=\frac12\log\cosh2K,\qquad A=2\sqrt{\cosh2K}.\]

分配関数の関係は\(Z_N(K)=A^{N/2}Z_{N/2}(K')\)となる。零温度近傍では\(K'\simeq K-\frac12\log2\)だから、\(v=e^{-2K}\)は\(v'\simeq2v\)と増える。零温度固定点から離れる変数が\(K\)自体より\(v\)であることが分かる。

\[T=\begin{pmatrix}e^{K+h}&e^{-K}\\e^{-K}&e^{K-h}\end{pmatrix},\qquad \lambda_\pm=e^K\left(\cosh h\pm\sqrt{\sinh^2h+e^{-4K}}\right).\]

転送行列の最大固有値から\(m=\partial_h\log\lambda_+\)を計算すると、本文の磁化の式が得られる。\(h=0\)では二つの固有値の比から\(\xi^{-1}=-\log\tanh K\)が求まる。
