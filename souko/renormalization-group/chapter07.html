7-1 模型

原著 印刷pp.202–203 / 提供PDF pp.212–213

原著は二次元Euclid時空の有質量Gross–Neveu模型を扱い、内部自由度の数をN > 1とする。ここでは符号と結合の規約を明示するため、四体相互作用を−λ(ψ̄ψ)²と書く。

\[S = \int d^{2}x [\sum _{a=1}^{N} \bar\psi_{a}((\gamma\cdot\partial) + m)\psi _{a} - \lambda (\sum _{a}\bar\psi_{a}\psi _{a})^{2}]\]

Fermi場の古典的な質量次元は(d−1)/2であり、d = 2では1/2。したがって四体演算子の次元は2となり、λは無次元である。Gaussian点では中立的なので、量子補正による結合の流れが本質になる。

二次元のFermi場の次元
\[[\psi]=\frac{d-1}{2},\qquad [(\bar\psi\psi)^2]=2(d-1),\qquad [\lambda]=2-d.\]

したがって\(d=2\)では四Fermi結合は古典的に中立である。この事実だけで正確に一定の結合になるのではなく、ループ補正が流れを決める。原著の\(N>1\)の条件は、相互作用の内部添字の和と相殺、β関数の係数に関係する。

「色」はこの模型の内部自由度の名称であり、ここで非可換ゲージ場を同時に導入しているわけではない。第5章のYang–Mills理論と同じ添字の名前が出てきても、作用と対称性は異なる。

7-2 補助場とFeynmanグラフ

原著 印刷pp.203–205 / 提供PDF pp.213–215

\[B \equiv \sum _{a} \bar\psi_{a}\psi _{a},\text{　} S_{\sigma } = \int d^{2}x [\bar\psi((\gamma\cdot\partial)+m)\psi + \sigma ^{2}/2 + √(2\lambda )\sigma B]\]
\[\sigma ^{2}/2 + √(2\lambda )\sigma B = (\sigma +√(2\lambda )B)^{2}/2 - \lambda B^{2}\]

σをGaussian積分で消せば、規格化定数を除いて元の四体相互作用を再現する。この書き換えで、グラフをFermi線と補助場線による頂点として整理できる。σはこの段階で独立な運動項を持つ基本粒子を追加したわけではない。

なぜFermi場でも尺度分解が役立つか

Fermi閉ループには符号が付き、内部添字の和がN依存を作る。原著は伝搬関数を正則化して尺度ごとに分解し、頂点、自己エネルギー、波動関数の補正を同じ指数配置の枠組みで計算する。これは単にβ関数だけを一度計算する作業ではなく、理論の構成へ向けた準備である。

読み方・注意

この章の対象は有質量・弱結合で制御する構成の問題である。質量ゼロ模型の動的質量生成や、大N近似の議論と無条件に同一視しない。

補助場を積分する方法と図の意味
\[\int D\sigma\,e^{-\int(\sigma^2/2+\sqrt{2\lambda}\sigma B)}=\text{定数}\times e^{+\lambda\int B^2}.\]

左辺の\(\sigma\)は微分項を持たないGaussian場なので、その裸の共分散は位置空間で局所的である。二つのYukawa型頂点を\(\sigma\)線で結ぶと元の四Fermi頂点を再現する。これがグラフを整理する補助的な道具となる。

ただし、原著では補助場の結合や元の四Fermi係数の間に特定の規約を置く。\(\lambda\)、\(g\)、\(g^2\)を同じ結合と思ってβ関数の係数やべきの数を比較しない。本ノートでは上の平方完成で規約を明示した。

7-3 部分くりこみの実行

原著 印刷pp.205–221 / 提供PDF pp.215–231

四点頂点と二点関数を分ける

尺度hまで処理した四点頂点の局所部分がδλ_hとなる。自己エネルギーを外部運動量で展開すると、定数項が質量、運動量一次のDirac構造が場の規格化に寄与する。これらを一段下の伝搬関数と結合へ組み入れる。

\[\Sigma _{h}(p) = A_{h} + B_{h}(\gamma \cdot p) + \text{残余}\]

この模式式のγ·pはpに線形なDirac構造を意味する。原著は具体的なグラフと指数の和を用いて係数を求める。内線の補正と頂点の補正は結び付いているため、一方だけを独立に選んで流れを決めてはならない。

漸近的自由性を表す最小の式

\[d\lambda /d \log Q = -b_{0}\lambda ^{2} + O(\lambda ^{3}),\text{　} b_{0} > 0\text{　}(N > 1)\]
\[\lambda (Q) \simeq \lambda (\mu )/[1 + b_{0}\lambda (\mu ) \log (Q/\mu )]\]

ここでλは四Fermi項の係数であり、前章のゲージ結合gとはべきの数が異なる。b_0の値はλの規格化とNに依存するので、本節では正の定数として示した。高運動量へ向かうほど結合が小さくなり、短距離の制御が可能になる。

次数化けと対数の積分

一段の場の規格化補正がλ_h²で始まっていても、多数の尺度を足し合わせると、最終結果が低エネルギー結合の一次で始まることがある。原著はこの現象を「次数化け」と呼ぶ。

\[\int _{\log \mu }^{\infty } \lambda (Q)^{2} d \log Q \simeq \lambda (\mu )/b_{0}\]

λが1/log Qで走る一ループ近似を代入すれば、二次の局所補正を積分したものが一次の大きさになることが分かる。これは高次項を自由に無視してよいという意味ではなく、反復と積分が摂動次数の数え方を変える例である。

読み方・注意

有限次数のβ関数が強結合領域に示す固定点を、そのまま厳密な赤外固定点と断定しない。弱結合で得た流れの有効範囲を守る。

尺度の和と漸近的自由性
\[\lambda(Q)=\frac{\lambda(\mu)}{1+b_0\lambda(\mu)\log(Q/\mu)}.\]

\(u=\log(Q/\mu)\)と置くと、各尺度の二次補正を足す積分は

\[\int_0^\infty du\,\frac{\lambda(\mu)^2}{(1+b_0\lambda(\mu)u)^2}=\frac{\lambda(\mu)}{b_0}.\]

この例は、各尺度では二次でも全尺度の和では一次になり得ることを具体的に示す。原著の次数化けの計算では、質量と場の補正も連立して扱うため、この簡単な積分だけで全ての係数が再現されるわけではない。

有限次数の結果から流れを解くこと、解を用いて摂動級数を組み替えること、その級数の収束を証明することは順に異なる段階である。第7章の後半は最後の段階へ進むために必要な仮定と評価を紹介する。

7-4 模型の構成

原著 印刷pp.221–228 / 提供PDF pp.231–238

裸の結合を切断とともに選ぶ

\[1/\lambda _{\mathrm{bare}}(\Lambda ) \simeq b_{0} \log (\Lambda /\mu ) + 1/\lambda _{R}(\mu )\]

低エネルギー結合を固定して切断Λを上げると、裸の結合はおおよそ1/log Λでゼロへ近づく。質量と場の規格化にも対応する調整が必要である。原著は高次の対数補正も含め、部分くりこみに適した裸の量の選び方を示す。

二つの級数を混同しない

部分くりこみ級数は、尺度ごとの有効結合をそのまま保持する多変数的な展開である。原著は、対象となる有質量・十分弱結合の領域で、相関関数をこの級数から収束的に構成する結果を紹介する。証明には本文で詳述しないクラスター展開や一様評価も必要になる。

一方、全てを単一のくりこまれた結合へ再展開した通常の摂動級数は発散する。それでもBorel総和可能なら、元の関数を回復できる。収束する部分くりこみ級数と、通常の級数のBorel和が一致することが重要になる。

\[F(\lambda ) \sim \sum _{n\ge 0} a_{n}\lambda ^{n},\text{　} B(t) = \sum _{n\ge 0} a_{n}t^{n}/n!\]
\[F_{B}(\lambda ) = (1/\lambda )\int _{0}^{\infty } \exp (-t/\lambda ) B(t) dt\]

B(t)の局所収束、正の実軸方向への解析接続、積分の成長条件が必要である。発散級数なら何でもBorel法で一意に定まるわけではない。例えばa_n = (−1)^n n!ならB(t) = 1/(1+t)となり、λ > 0で上の積分が定義できる。

Euclid場から量子論へ

構成したSchwinger関数が既知のBorel構成などと一致し、Osterwalder–Schraderの条件を満たすことを通じて、Minkowski空間の量子論へつなぐ。形式的なグラフ計算の正しさと、物理的な場の理論の存在を結び付けるのが、この章の到達点である。

読み方・注意

漸近的自由性は構成の重要な入力だが、それだけで構成の証明が終わるわけではない。極限・収束・公理の確認が残る。

例：発散する級数から関数を回復する
\[F(\lambda)\sim\sum_{n=0}^\infty(-1)^n n!\lambda^n,\qquad B(t)=\frac1{1+t}.\]
\[F_B(\lambda)=\frac1\lambda\int_0^\infty\frac{e^{-t/\lambda}}{1+t}\,dt=\int_0^\infty\frac{e^{-u}}{1+\lambda u}\,du\quad(\lambda>0).\]

\(1/(1+\lambda u)\)を有限次数で幾何級数に展開し、残余まで含めて積分すると、係数が\((-1)^n n!\)になることを確認できる。関数が存在することと、原点の通常のTaylor級数が収束することは同じではない。

Gross–Neveu模型の構成では、原著が指定する有質量・十分弱結合の領域、解析性、体積と切断に関する一様性が重要になる。単なる形式的なBorel変換では足りず、積分路付近の解析接続と増大度の条件が必要である。

章の到達点

走る結合が小さいという紫外の情報を、全尺度の誤差を抑える評価へ変換し、相関関数の存在へ結び付ける。RGは発散を相殺する記号操作から、場の理論を作る方法へ進む。
