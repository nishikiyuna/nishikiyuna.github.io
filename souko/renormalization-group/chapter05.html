5-1 場の量子論

原著 印刷pp.115–118 / 提供PDF pp.125–128

場の量子論のGreen関数は、真空での時間順序積の期待値で定義される。原著はMinkowski時空の定式化から始め、摂動計算や発散の評価にEuclid表示も用いる。本ノートではiの因子や符号の混乱を避けるため、生成汎関数の主要な関係をEuclid規約でまとめる。

\[Z[J] = \int D\varphi \exp (-S[\varphi ] + \int J\varphi ),\text{　} W[J] = \log Z[J]\]
時間順序積と生成汎関数
\[G_M^{(n)}(x_1,\ldots,x_n)=\langle\Omega|T\{\widehat\varphi(x_1)\cdots\widehat\varphi(x_n)\}|\Omega\rangle.\]

\(T\)は時刻の順序に演算子を並べる操作である。Fermi場では並べ替えの符号も含む。相関関数から散乱振幅へ進む際には、外線の極や留数に関する手続きが必要であり、単に四点相関の数値が散乱確率になるわけではない。

Wick回転は、収束や解析性が許す範囲でMinkowski表示とEuclid表示を関係づける。形式的に\(t\mapsto-i\tau\)と置き換えるだけで、任意の理論の非摂動的な再構成が保証されるわけではない。第4章の構成の問題と、この区別はつながっている。

5-2 Green関数と頂点関数

原著 印刷pp.118–123 / 提供PDF pp.128–133

\[G^{(n)}_{c} = \delta ^{n}W / \delta J^{n},\text{　} \phi = \delta W/\delta J\]
\[\Gamma [\phi ] = \int J\phi - W[J],\text{　} \delta \Gamma /\delta \phi = J\]

Zの微分は一般の相関関数、Wの微分は連結相関関数を作る。ΓはLegendre変換であり、その微分Γ⁽ⁿ⁾が1粒子既約（1PI）頂点関数となる。1PIグラフは一本の内線を切っても二つに分離しない。連結グラフのすべてが1PIとは限らない。

\[\Gamma ^{(2)} G^{(2)}_{c} = 1\text{　　}(\text{積分核としての逆関係})\]

自由場ではΓ⁽²⁾(p) = p²+m²。相互作用があると自己エネルギーがこれを補正する。高次の相関関数は、完全伝搬関数と1PI頂点を組み合わせて再構成できるため、くりこみを1PI関数で整理すると重複を避けやすい。

対象図式的な意味使いどころ
G⁽ⁿ⁾外点を持つ全グラフ観測する相関
G_c⁽ⁿ⁾連結なグラフ独立でない揺らぎ
Γ⁽ⁿ⁾1粒子既約グラフ頂点・自己エネルギーのくりこみ
読み方・注意

記号を見たら、全相関か連結相関か1PIかを確認する。場のくりこみに伴うZ因子の向きは、どの関数を扱うかで変わる。

導出：Legendre変換が二点核を逆にする
\[\frac{\delta\Gamma}{\delta\phi(x)}=J(x),\qquad \frac{\delta\phi(y)}{\delta J(z)}=G_c^{(2)}(y,z).\]

第一式を\(J(z)\)で微分して連鎖律を使うと、

\[\int dy\,\Gamma^{(2)}(x,y)G_c^{(2)}(y,z)=\delta(x-z).\]

これが完全伝搬関数と1PI二点頂点の逆関係である。相互作用を含む逆伝搬関数に自己エネルギーをまとめると、内線の反復挿入を幾何級数として整理できる。

\[G=(G_0^{-1}+\Sigma_E)^{-1}.\]

ここではEuclidの自己エネルギーを\(\Gamma^{(2)}=G_0^{-1}+\Sigma_E\)と定義した。Minkowskiの慣用的な符号と比較するときは、\(i\)の因子と自己エネルギーの定義を揃える。

5-3 くりこみの処方

原著 印刷pp.123–137 / 提供PDF pp.133–147

裸の量とくりこまれた量

\[\varphi _{0} = Z_{\varphi }^{1/2}\varphi _{R},\text{　} m_{0}^{2} = m_{R}^{2} + \delta m^{2}\]
\[\lambda _{0} = \mu ^{\varepsilon }(\lambda _{R} + \delta \lambda ),\text{　} d = 4-\varepsilon \]

ここでδλは必要な場のZ因子も含めた結合の反項として定義した。作用をくりこまれた量で書くと、元の形と、質量・波動関数・結合に対応する反項に分かれる。各次数で反項を調整し、指定したΓ⁽²⁾、Γ⁽⁴⁾などの条件を満たすようにする。

質量殻の条件とMS法

質量殻の処方では伝搬関数の物理的な極、極の留数、指定した運動学での散乱頂点を基準にする。最小引算法（MS）は次元正則化で現れるεの極だけを差し引く。MSの質量・結合は、観測量と同じ値であるとは限らず、有限な変換を介して対応させる。

\[\mu ^{\varepsilon } \int [d^{d}k/(2\pi )^{d}] (k^{2}+M^{2})^{-2}\]
\[= (1/16\pi ^{2})[2/\varepsilon - \gamma _{E} + \log (4\pi \mu ^{2}/M^{2}) + O(\varepsilon )]\]

μはd ≠ 4で結合の次元を合わせるために導入するスケールである。発散の極を除いてもlog(μ²/M²)は残る。任意のμへの依存を結合の変化で打ち消すことが、後のRG方程式の出発点となる。MSと、定数−γ_E+log4πも除くMS-barは区別する。

何が「くりこみ可能」なのか

4次元のφ⁴理論では、対称性と発散次数により、必要な局所反項の型を有限個に絞れる。ただし有限個の反項で各摂動次数を有限にできることは、級数全体の収束や非摂動的連続極限を保証しない。

読み方・注意

正則化は一時的な計算の定義、くりこみはパラメタの意味づけ。切断やεと、物理的な基準スケールμを混同しない。

導出：Schwingerパラメタでループ積分を計算する
\[\frac1{(k^2+M^2)^a}=\frac1{\Gamma(a)}\int_0^\infty ds\,s^{a-1}e^{-s(k^2+M^2)}.\]

収束する領域では積分順序を入れ替え、\(k\)のGaussian積分を先に行う。

\[\int\frac{d^dk}{(2\pi)^d}e^{-sk^2}=(4\pi s)^{-d/2}.\]

残る\(s\)積分はΓ関数になる。\(a=2,d=4-\varepsilon\)なら\(\Gamma(\varepsilon/2)=2/\varepsilon-\gamma_E+\cdots\)。この極が反項へ吸収される。反項には対称性で許される局所構造だけを用い、各次数で決めた条件と整合するようにする。

次元正則化の\(\varepsilon\)は計算を定義する補助変数として最後にゼロへ戻すことが多い。一方、臨界現象の\(4-\varepsilon\)展開では次元そのものを固定して考える。この二つの役割を同じ操作と思わないこと。

5-4 くりこみ群1：質量殻上でくりこむ場合

原著 印刷pp.137–141 / 提供PDF pp.147–151

伝搬関数や四点頂点から無次元の不変結合を作り、基準スケールを変える。二段階で基準を動かしても一度で動かしても同じ結果になる、という関数方程式が成立する。以下はμの比をsとする簡略化した表示である。

\[\bar g(st,g) = \bar g(s,\bar g(t,g)),\text{　} \bar g(1,g) = g\]

質量があると、無次元のm/μも同時に変換されるため一変数の式だけでは閉じない。原著はこの質量依存を残した関数方程式から議論する。

基準点を二回変える

\(\mu_0\to\mu_1\to\mu_2\)と基準点を動かす。\(s=\mu_1/\mu_0\)、\(t=\mu_2/\mu_1\)なら、全体の倍率は\(st\)である。途中の結合\(\bar g(s,g)\)を次の変換の入力に使うことが、合成則の内容となる。

\[\bar g(st,g)=\bar g(t,\bar g(s,g)).\]

Green関数の規格化には、途中の結合に依存する倍率の積が付く。従って、結合の変換と場の変換を独立に好きな形へ選ぶことはできない。質量比もある場合は、その変化を含む多変数の合成則へ拡張する。

5-5 Ovsiannikovの方程式

原著 印刷pp.141–145 / 提供PDF pp.151–155

有限変換の合成則を無限小変換で微分すると、結合やGreen関数の基準点への応答を表す偏微分方程式を得る。原著でx = p²/λ²、y = m²/λ²とした表示では、Ovsiannikov方程式は次の形を持つ。

\[[x\partial _{x} + y\partial _{y} - \phi (y,g)\partial _{g}] \bar h(x,y,g) = 0\]

同じ合成則を別の変数で微分すれば、流れに沿った常微分方程式も得られる。両者は特性曲線を介して結び付く。原著のλは本節では基準運動量を意味し、四次結合λとは異なる。

導出：有限変換の微分と特性曲線

\(\tau=\log s\)として\(g(\tau)=\bar g(e^\tau,g_0)\)を考える。無限小の変換の生成関数を\(\beta(g)\)と定義すると、

\[\frac{dg(\tau)}{d\tau}=\beta(g(\tau)),\qquad g(0)=g_0.\]

観測量\(F\)が\(\partial_\tau F+\beta(g)\partial_gF=\gamma_F(g)F\)を満たす場合、\(g(\tau)\)に沿う微分は単なる一階方程式となる。

\[\frac{dF}{d\tau}=\gamma_F(g(\tau))F,\qquad F(\tau)=F(0)\exp\!\left[\int_0^\tau\gamma_F(g(u))du\right].\]

質量依存を含むOvsiannikov方程式では、同じ考えで質量比の特性曲線も同時に解く。偏微分方程式と走る結合の常微分方程式は、別の物理を記述する二つの理論ではない。

5-6 Gell-Mann–Lowの公式

原著 印刷pp.145–147 / 提供PDF pp.155–157

\[d \bar g/d \log s = \beta _{\mathrm{RG}}(\bar g),\text{　} \log s = \int _{g}^{\bar g(s)} du/\beta _{\mathrm{RG}}(u)\]

質量を無視できる高エネルギー領域で、結合の流れは一変数へ簡略化される。摂動論で得たβ関数を積分すると、大きな対数をまとめた有効結合を得る。これは一つのスケールでの小さな補正を反復して、離れたスケールへ情報を運ぶ操作である。

読み方・注意

原著のϕはp²を基準にした変数を用いる。本ノートのβ_RG = d g/d log μとは、変数の二乗に由来する係数2などを確認して比較する。

計算例：主要対数の再和
\[\beta(g)=b g^2\quad\Longrightarrow\quad \bar g(s)=\frac{g}{1-bg\log s}.\]
\[\bar g(s)=g+bg^2\log s+b^2g^3(\log s)^2+\cdots.\]

一ループのβ関数を積分すると、各次数の主要な対数\(g^{n+1}(\log s)^n\)をまとめて取り込める。ただし二ループ以降のβ関数が作る劣主要対数や、同じ次数の定数項まで自動的に正しくなるわけではない。

\(g\log s\)が小さくなくても\(\bar g(s)\)が小さい範囲なら、RGで改善した記述が役立つ。逆に走る結合自体が大きくなる領域では、主要対数を足した式だけでは制御できない。

5-7 φ⁴模型の場合

原著 印刷pp.147–150 / 提供PDF pp.157–160

\[\beta _{\mathrm{RG}}(\lambda ) = 3\lambda ^{2}/(16\pi ^{2}) + O(\lambda ^{3})\]
\[\lambda (Q) = \lambda (\mu ) / [1 - {3\lambda (\mu )/(16\pi ^{2})} \log (Q/\mu )]\]

正の弱結合では、Qを上げるとλが増える。分母がゼロになる形式的なLandau尺度はQ_L = μ exp[16π²/(3λ(μ))]。ただしその前に弱結合近似は失われるため、この式だけで理論の厳密な特異性を証明できるわけではない。原著は摂動次数で流れの予測が変わる問題も検討する。

Landau尺度をどう解釈するか
\[\int_{\lambda(\mu)}^{\lambda(Q)}\frac{d\lambda}{3\lambda^2/(16\pi^2)}=\log\frac Q\mu.\]

積分の右端を無限大にすると有限の\(\log(Q/\mu)\)が得られる。これが一ループ近似におけるLandau尺度の由来である。だが、そこへ到達する前に高次補正が無視できなくなる。

原著が高次のβ関数で現れる固定点の不安定さを検討するのは、この問題を一つの低次近似だけで決着させられないためである。固定点が現れたら、その位置が摂動領域にあるか、次数を上げたとき安定か、非摂動的な情報と整合するかを確認する。

5-8 Callan–Symanzikの方程式

原著 印刷pp.150–154 / 提供PDF pp.160–164

裸の伝搬関数を質量で微分すると、内線に質量項を挿入したグラフが現れる。すべての内線への挿入を合わせることで、頂点関数の質量変化を表すCallan–Symanzik方程式が導かれる。

\[[m\partial _{m} + \beta _{CS}(g)\partial _{g} - n\gamma _{\varphi }(g)] \Gamma ^{(n)}_{R} = \Gamma ^{(n)}_{\mathrm{mass insertion}}\]

この式の係数と右辺は、質量微分および複合演算子の規約に依存する。質量が無視できる高運動量極限では、挿入項の影響を評価した上で、同次のスケーリング式へ近づける。右辺を理由なくゼロと置くことはできない。

異常次元の意味

場の規格化がスケールとともに変わると、頂点関数には古典的な次元だけでは決まらない因子が付く。固定点では結合が一定でも場のZ因子は走り得る。これが相関関数のべき指数のずれ、すなわち異常次元を生む。

\[\Delta _{\varphi } = (d-2)/2 + \gamma _{\varphi }*,\text{　} \eta = 2\gamma _{\varphi }*\]
読み方・注意

このγ_φは位置空間の場に対する規約。原著のγや場の指数θは定義が異なる場合がある。物理的な相関の指数へ戻して比較する。

質量微分と複合演算子の挿入
\[\frac{\partial}{\partial m^2}\frac1{k^2+m^2}=-\frac1{(k^2+m^2)^2}.\]

右辺は、一本の内線に質量頂点を挿入した構造である。汎関数積分では、\(m^2\)の微分は作用中の\(\frac12\int\varphi^2\)の挿入になる。

\[\frac{\partial\langle O\rangle}{\partial m^2}=-\frac12\left\langle O\int d^dx\,\varphi(x)^2\right\rangle_c.\]

この複合演算子自身にもくりこみが必要となる。Callan–Symanzik方程式の右辺を単に「質量が小さいからゼロ」と扱う前に、高運動量での挿入の大きさを評価することが必要である。固定点での場の異常次元と、質量演算子の異常次元も区別する。

5-9 くりこみ群2：最小引算法の場合

原著 印刷pp.154–155 / 提供PDF pp.164–165

MS法では、くりこみ定数はεの極のLaurent級数となる。裸の結合や裸の場はμに依存しないようにしなければならない。その条件を微分すると、有限なβ関数と異常次元が決まる。

\[\beta _{\mathrm{RG}}(g) = \mu dg/d\mu |_{\mathrm{bare}},\text{　} \gamma _{\varphi } = \tfrac12 \mu d \log Z_{\varphi }/d\mu |_{\mathrm{bare}}\]

d = 4−εでのβ関数には、結合の古典的な次元による−εgが含まれる。4次元の極限でこの項を落とすことと、εを小さな正数に固定してWilson–Fisher点を探すことは別の操作である。

MSと物理的な条件の役割

MSの利点は、発散部分を極の係数として系統的に計算できることである。一方、その結合は特定の散乱実験で直接読む値ではない。物理的に定義した結合へ移すには、同じ精度で頂点を計算し有限な変換を求める。

\[g_{\mathrm{phys}}=g_{\mathrm{MS}}+c_1g_{\mathrm{MS}}^2+c_2g_{\mathrm{MS}}^3+\cdots.\]

どちらの結合を使っても、変換と摂動次数を揃えれば観測量は一致する。有限次数で残る処方依存は、計算で省いた高次項の影響を含む。処方を変えて結合値が変わったことだけを、物理が変わった証拠としない。

5-10 Weinberg–’t Hooftの方程式

原著 印刷pp.155–159 / 提供PDF pp.165–169

\[[\mu \partial _{\mu } + \beta _{\mathrm{RG}}\partial _{g} + \beta _{m^{2}}\partial _{m^{2}} - n\gamma _{\varphi }] \Gamma ^{(n)}_{R} = 0\]

β_m² ≡ μ d m²/dμと定義した。裸の1PI頂点とくりこまれた頂点の関係Γ_R⁽ⁿ⁾ = Z_φ^(n/2) Γ_0⁽ⁿ⁾から、上のZ因子の符号が定まる。原著では質量項を−mγ_m∂_mと書く規約も用いる。

\[\lambda _{0} = \mu ^{\varepsilon }[\lambda + a_{1}(\lambda )/\varepsilon + a_{2}(\lambda )/\varepsilon ^{2} + \cdots ]\]
\[\beta _{4D}(\lambda ) = \lambda a'_{1}(\lambda ) - a_{1}(\lambda )\]

結合の定義に場のZ因子を吸収した上の表示では、単純極の係数が4次元のβ関数を与える。a_1 = 3λ²/(16π²)を代入すれば、一ループの結果が戻る。高い極の係数は独立に自由ではなく、有限性の整合条件で関係づけられる。

処方を変えると何が変わるか

結合の有限な再定義g′ = f(g)をすると、β′(g′) = f′(g)β(g)。有限次数の結合値や固定点の座標は処方に依存する。一方、適切に比較した物理的観測量や固定点まわりの普遍的な指数は、座標の選択によらない。

読み方・注意

μ依存を持つ結合は観測量そのものではない。物理的な予測では、結合の走りと頂点・伝搬関数の明示的なμ依存を一緒に扱う。

導出：単純極がβ関数を決める

\(\lambda_0=\mu^\varepsilon F(\lambda,\varepsilon)\)と書き、裸の\(\lambda_0\)を固定して微分する。

\[0=\varepsilon F+\beta_d(\lambda)\,\partial_\lambda F,\qquad \beta_d=-\varepsilon\lambda+\beta_{4D}(\lambda).\]

\(F=\lambda+a_1/\varepsilon+a_2/\varepsilon^2+\cdots\)を代入し、有限部分を比較すると本文の\(\beta_{4D}=\lambda a_1'-a_1\)が得られる。さらに極の係数を比較すると、\(a_2,a_3,\ldots\)の整合条件が得られる。

固定点の座標が\(g'=f(g)\)で変わっても、\(f'(g_*)\ne0\)の正則な変換なら、線形化した流れの固有指数は変わらない。これは臨界指数が理論空間の座標に依存しないことの一変数での例である。

5-11 高エネルギー極限

原著 印刷pp.159–163 / 提供PDF pp.169–173

RG偏微分方程式を、有効結合・有効質量・場の規格化の常微分方程式に分解する。Q ≫ mの領域ではμをQ程度に選び、残る対数を小さくした摂動計算に、μからQまでの走りを組み合わせる。質量の無視が正当か、運動学に赤外特異性がないかは別に確認する。

古典的次元と異常次元を合わせる

質量を無視できる範囲では、\(n\)点1PI頂点の古典的な質量次元は\(D_n=d-n(d-2)/2\)。次元解析による運動量倍率と、RGによる場の倍率を組み合わせる。

\[\Gamma_R^{(n)}(\{s p_i\};g,\mu)=s^{D_n}\exp\!\left[-n\int_1^s\gamma_\varphi(\bar g(u))\frac{du}{u}\right]\Gamma_R^{(n)}(\{p_i\};\bar g(s),\mu).\]

ここでは\(\Gamma_R^{(n)}=Z_\varphi^{n/2}\Gamma_0^{(n)}\)と本文の\(\gamma_\varphi\)の規約を用いる。固定点では\(\gamma_\varphi\)が一定となり、頂点のべきは\(D_n-n\gamma_\varphi^*\)になる。二点頂点では\(p^{2-\eta}\)、伝搬関数ではその逆の\(p^{-2+\eta}\)となる。

5-12 いろいろの模型

原著 印刷pp.163–169 / 提供PDF pp.173–179

\[\beta _{\mathrm{RG}}(g) = -b_{0}g^{3} + \cdots ,\text{　} b_{0} > 0\]
\[1/g^{2}(Q) = 1/g^{2}(\mu ) + 2b_{0} \log (Q/\mu )\]

この場合はQ → ∞でg(Q) → 0となり、短距離で摂動論が使いやすくなる。4次元の純粋な非可換Yang–Mills理論が代表例である。物質場を加えると係数は変わるため、非可換であるだけで常に漸近的自由とは言えない。

模型・領域弱結合での高Qへの走り注意
4次元の正のφ⁴結合増加弱結合の範囲を越えると推論に限界
QEDの通常の弱結合領域増加有限次数の流れだけで紫外完結性は決まらない
純粋Yang–Mills理論減少紫外で自由。赤外の強結合は別問題
非可換ゲージ理論の一ループの符号
\[\beta(g)=-\frac{g^3}{16\pi^2}\left(\frac{11}{3}C_A-\frac43T_RN_f\right)+\cdots.\]

これは4次元で、同じ表現のDiracフェルミオンを\(N_f\)個含む場合の慣用的な規約である。\(C_A\)は随伴表現の二次Casimir、\(T_R\)は物質表現の規格化。純粋Yang–Millsでは括弧が正なのでβは負となる。物質場を増やすと符号が変わり得る。

原著の模型比較の要点は、結合の増減を一般的な標語で決めず、β関数と適用範囲を見ることである。紫外で小さい結合を得ることは、赤外での閉じ込めなどの強結合問題を解いたことを意味しない。

5-13 補遺：非整数次元空間における積分

原著 印刷pp.169–172 / 提供PDF pp.179–182

\[\int [d^{d}k/(2\pi )^{d}] (k^{2}+M^{2})^{-a}\]
\[= (4\pi )^{-d/2} \Gamma (a-d/2) (M^{2})^{d/2-a} / \Gamma (a)\]

まず収束する領域でGaussian積分やΓ関数の表示から導き、dやaについて解析接続する。Γ関数の極が紫外発散を表す。ただし次元を下げる操作が赤外発散を導入する場合もあるため、紫外の極と赤外の極を区別する。

読み方・注意

第1章の高エネルギー・スケーリングへ戻ると、有効結合がゆっくり走ることが、単純な尺度不変性の対数的な破れを説明する。

非整数次元の球面積と解析接続
\[\int d^dk\,f(k^2)=\frac{2\pi^{d/2}}{\Gamma(d/2)}\int_0^\infty dk\,k^{d-1}f(k^2).\]

係数は\(\int d^dk\,e^{-k^2}=\pi^{d/2}\)に合うよう定まる。正整数の次元で得た積分表示を、Γ関数を介して複素の\(d\)へ解析接続する。

\[\int\frac{d^dk}{(2\pi)^d}\frac1{(k^2+M^2)^a}\propto\Gamma(a-d/2).\]

\(a-d/2\)が0、負の整数に近づくとΓ関数に極が現れる。正の質量\(M\)を保てば低運動量は抑えられるが、\(M=0\)では赤外にも問題が生じる。尺度を持たない積分が正則化の規約でゼロになることを、紫外と赤外の両方に発散がないという意味に取り違えない。
