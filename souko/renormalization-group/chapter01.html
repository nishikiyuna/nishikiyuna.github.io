1-1 自然法則の不変性

原著 印刷pp.1–2 / 提供PDF pp.11–12

保存則や時空変換の不変性と同じく、スケール変換も法則の構造を制約する。ただし現実の系で尺度不変性が成立するのは、多くの場合、臨界点や高エネルギーなど特定の極限においてである。有限の相関距離や質量は固有の長さを与え、厳密な尺度不変性を破る。

不変と共変を分ける

変換して量そのものが同じ値を保つ場合を不変と呼び、既知の因子を伴って変わる場合を共変と呼ぶ。スケーリングでは、観測量が完全に一定になる必要はない。長さを変えたときに、次元に応じたべき因子を取り出せれば、残る無次元の関係に不変性を見いだせる。

\[F(bx)=b^{-\Delta}F(x)\quad\Longrightarrow\quad F(x)=A x^{-\Delta}\quad(x>0).\]

指数関数には固有の長さがある。例えば \(G(x)=e^{-x/\xi}\) は、\(\xi\)を固定したままでは上のべき則に従わない。臨界点で\(\xi\)が発散すると、有限の観測距離に固有の尺度が見えなくなる。

1-2 スケーリングと漸近的法則

原著 印刷pp.2–11 / 提供PDF pp.12–21

\[F(b^{a}x, b^{c}y) = b^{w}F(x,y)\]

x > 0、a ≠ 0 として b = x^(−1/a) を選ぶと、二変数への依存を一つの組合せにまとめられる。これは単なる次元解析より広い。非線形なスケーリング関数が飽和やクロスオーバーも記述する。

\[F(x,y) = x^{w/a} \Phi (y x^{-c/a})\]

漸近的な同次性では、この式に小さな補正が付く。補正がどの程度速く消えるかは、後に登場する非有効な摂動の固有指数で理解できる。一方、全領域で同次式が成立するかどうかは変数の選び方にも依存する。

高エネルギーと幾何学の二つの例

深部非弾性散乱のBjorken極限では、運動量移行とエネルギー移行を大きくしつつ、それらの比で定まる無次元変数を固定する。構造関数が主としてこの比に依存することがスケーリングであり、相互作用の走りは対数的な破れを生む。厳密な導出には第1章の概観を越える道具が必要になる。

\[D = \log N / \log b\text{　　}(Koch\text{曲線}：D = \log 4 / \log 3)\]

長さを1/bに縮めた自己相似な部分がN個あるなら、このDが相似次元となる。幾何学では細部の追加と縮尺の変更、統計物理では自由度の積分と再尺度化が対応する。ただし自己相似な図形の類推だけで物理模型の指数が決まるわけではない。

読み方・注意

要点：スケーリング則は「一つの尺度で知った情報を別の尺度へ移す」規則。RGは、その規則をミクロな自由度の処理から導く方法である。

導出：同次性を微分方程式で書く

同次式を\(b\)で微分して\(b=1\)とすると、Euler型の方程式になる。

\[\left(a x\frac{\partial}{\partial x}+c y\frac{\partial}{\partial y}\right)F=wF.\]

この偏微分方程式の特性曲線上では、\(y x^{-c/a}\)が一定となる。したがって同次式の解が一つのスケーリング関数で表されることを、微分方程式からも確認できる。

\[F(x,y,u)=x^{w/a}\left[\Phi(yx^{-c/a})+u\,x^{\omega/a}\Phi_1(yx^{-c/a})+\cdots\right].\]

最後の式は、\(u\)が変換で\(u\mapsto b^{-\omega}u\)、\(\omega>0\)と減衰する場合の補正の例である。指数\(\omega\)が小さいと漸近領域へ近づくのは遅い。数値データが直線に見える範囲だけから指数を読み取ると、補正を主要なべきに取り込んでしまうことがある。

物理の例：データを重ねる

\(m(t,h)=|t|^{\beta_{\mathrm{mag}}}\mathcal M_\pm(h/|t|^{\beta_{\mathrm{mag}}\delta})\)なら、縦軸を\(m/|t|^{\beta_{\mathrm{mag}}}\)、横軸を\(h/|t|^{\beta_{\mathrm{mag}}\delta}\)にすると異なる温度の曲線が重なる。これはデータ崩壊と呼ばれる確認法である。ただし近似的な重なりだけで、スケーリングの成立や指数の一意性を証明できるわけではない。
