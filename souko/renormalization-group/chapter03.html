3-1 φ⁴模型の統計力学

原著 印刷pp.39–48 / 提供PDF pp.49–58

\[S[\varphi ] = \tfrac12 \sum _{\langle xy\rangle }(\varphi _{x}-\varphi _{y})^{2} + \sum _{x}[r\varphi _{x}^{2}/2 + \lambda \varphi _{x}^{4}/4!]\]

各格子点の実数変数φ_xをGibbs重みexp(−S)で平均する。四次項はλ > 0で大振幅を抑える。rを変えると対称相と秩序相が現れ、相境界の値r_cは一般にλに依存する。したがって、相互作用系の臨界点をr = 0と最初から同一視してはいけない。

\[G_{c}(x-y) = \langle \varphi _{x}\varphi _{y}\rangle - \langle \varphi _{x}\rangle \langle \varphi _{y}\rangle ,\text{　} \chi = \sum _{x}G_{c}(x)\]

相関距離ξは、臨界点から離れたときの相関の指数減衰を特徴づける。連結4点関数は、2点相関だけでは表現できない相互作用の指標になる。原著ではこれらの量をRGの変換則と結び付けて解析する。

観測量を定義する順序
\[Z_\Lambda(h)=\int\prod_{x\in\Lambda}d\varphi_x\;e^{-S[\varphi]+h\sum_x\varphi_x},\qquad f=-\lim_{|\Lambda|\to\infty}\frac{\log Z_\Lambda}{|\Lambda|}.\]

\(m=-\partial_h f\)、\(\chi=\partial_hm\)と定義すると、\(\chi\)が連結2点関数の和になる。有限体積で計算してから熱力学的極限をとり、対称性の破れを調べるときはその後で\(h\to0^+\)とする。順序を逆にすると、有限体積の対称性のため磁化は常にゼロとなる。

\[\chi=\frac1{|\Lambda|}\left[\left\langle\left(\sum_x\varphi_x\right)^2\right\rangle-\left\langle\sum_x\varphi_x\right\rangle^2\right].\]

この式は、応答としての磁化率と、平衡揺らぎの大きさとを結ぶ。くりこみ群で\(\chi\)を変換するときにも、この定義へ戻れば長さと場の倍率を確かめられる。

3-2 Gauss模型

原著 印刷pp.48–52 / 提供PDF pp.58–62

\[\widetilde G(k) = 1/(\widehat k^{2}+r),\text{　} \widehat k^{2} = 4\sum _{j=1}^{d} \sin ^{2}(k_{j}/2)\]

λ = 0なら二次形式を対角化するGaussian積分に帰着する。低波数ではk̂² ≃ k²となり、r > 0でξ ≃ r^(−1/2)、χ = r^(−1)を得る。質量ゼロの無限体積極限では、d > 2で長距離相関がべき則になる。

\[G_{c}(x) \propto |x|^{-(d-2)}\text{　}(r = 0, d > 2)\]

Gaussian理論では高次の相関関数を2点関数の組合せで表せる。Wickの定理が摂動展開の出発点になる。一方、有限体積の零モードと質量ゼロ極限には注意が必要であり、積分や極限の順序を曖昧にしない。

読み方・注意

Gaussian理論は臨界指数の出発点だが、相互作用による揺らぎが長距離で増える次元では、臨界現象の最終的な答えにならない。

Gaussian積分とWickの定理
\[\frac{Z_0[J]}{Z_0[0]}=\exp\!\left(\frac12 J C J\right),\qquad C=(-\Delta+r)^{-1}.\]

右辺を外場\(J\)で微分すると、奇数個の場の平均はゼロ、偶数個の場の平均は全ての対の組み合わせの和になる。例えば

\[\langle\varphi_1\varphi_2\varphi_3\varphi_4\rangle_0=C_{12}C_{34}+C_{13}C_{24}+C_{14}C_{23}.\]

Fourier空間で\(C(k)\simeq(k^2+r)^{-1}\)となることから、長距離の形は\(|x|/\xi\)を使って書ける。

\[G(x;r)=|x|^{2-d}\,\mathcal G(|x|\sqrt r).\]

臨界点では\(\mathcal G(0)\)が有限となる範囲でべき則を得る。遠方では指数的な減衰が現れる。格子の詳細は高波数に現れるが、\(|x|\gg a\)では低波数の二次式が主要な役割を担う。

3-3 摂動展開

原著 印刷pp.52–56 / 提供PDF pp.62–66

exp(−λV)を展開しGaussian平均をとると、相関関数はFeynmanグラフの和になる。分配関数で割ることは真空グラフの寄与を取り除き、連結部分に注目することは観測量に対応した整理を与える。

\[I_{2}(r) = \int _{|k|<\Lambda } [d^{d}k/(2\pi )^{d}] (k^{2}+r)^{-2}\]

r → 0に対して、2 < d < 4ではI_2がr^((d−4)/2)のように増大し、d = 4では対数が現れる。小さいλでもλI_2が大きくなると有限次数の計算を信頼できない。これは低運動量、つまり大きな長さの揺らぎに由来する赤外の問題である。

計算例：一ループの二つの補正

\(\lambda\varphi^4/4!\)の規約では、一つの頂点の二本を縮約したtadpoleが質量を補正し、二つの頂点を結ぶbubbleが四点頂点を補正する。

\[\delta r=\frac\lambda2\int_k\frac1{k^2+r},\qquad \delta\lambda=-\frac{3\lambda^2}{2}\int_k\frac1{(k^2+r)^2}+\cdots.\]

ここで\(\int_k=\int d^dk/(2\pi)^d\)。第二式は殻積分で低エネルギー結合を作る向きの符号であり、全運動量の一度の積分では赤外・紫外の切断を明示する必要がある。

\[\int_k(k^2+r)^{-2}\sim r^{(d-4)/2}\quad(2<d<4).\]

\(r\)が小さいと各次数の係数が大きくなるため、\(\lambda\ll1\)だけでは制御できない。展開の小ささを\(\lambda r^{(d-4)/2}\)などの無次元量で判断しなければならない。これが、臨界点で単純な摂動展開をそのまま使えない理由である。

3-4 くりこみ変換

原著 印刷pp.56–64 / 提供PDF pp.66–74

\[\varphi = \varphi _{<} + \varphi _{>},\text{　} \exp (-S_{\mathrm{eff}}[\varphi _{<}]) = \int D\varphi _{>} \exp (-S[\varphi ])\]

運動量殻Λ/b < |k| < Λの自由度を積分する。その後、x = bx′とおき、勾配項が同じ規格化になるよう場を調整する。この殻積分の図式は長波長での説明に適している。原著ではブロックスピン変換の正確な定義を与えたうえで、その低波数近似との関係を検討する。

\[\varphi '(x') = b^{(d-2)/2} \varphi _{<}(bx')\]
\[r' = b^{2}r,\text{　} \lambda ' = b^{4-d}\lambda \text{　}(Gaussian\text{点の線形項})\]

積分後にはφ⁶、勾配を含む項、非局所項なども生じる。元のφ⁴形だけへ射影することは厳密な変換とは異なる。長距離でそれらが小さくなることを、固有摂動の分類と誤差評価で確かめるのがRGの方法論である。

読み方・注意

二つの困難を分ける：第3章の臨界点近傍の摂動破綻は主に赤外の問題。第4–6章で切断を除く際に現れる高運動量の発散は紫外の問題である。

再尺度化による古典的な固有指数

\(x=bx'\)、\(\varphi(x)=b^{-(d-2)/2}\varphi'(x')\)を代入すると、勾配項の係数は変わらず、質量項と四次項だけが異なる倍率を受ける。より一般に\(\varphi^{2n}\)の係数のGaussian点での指数は

\[y_{2n}=d-n(d-2).\]

\(d=4\)では\(y_2=2\)、\(y_4=0\)、\(y_6=-2\)。したがって弱結合近傍では質量と四次結合を中心に追う根拠がある。ただし勾配項の規格化や、他の対称性を許す演算子も確認する必要がある。

この分類は固定点での局所的な分類であり、任意に大きな初期結合から始めた流れを保証するものではない。まずどの固定点の近傍にいるかを指定して初めて、有効・非有効という言葉に意味が生じる。

3-5 くりこみ変換の摂動展開

原著 印刷pp.64–72 / 提供PDF pp.74–82

\[S_{\mathrm{eff}} = S_{0,<} + \langle V\rangle _{>} - \tfrac12 (\langle V^{2}\rangle _{>}-\langle V\rangle _{>}^{2}) + \cdots \]

一次の収縮が主として質量項を補正し、二次の収縮が結合と運動量依存性を変える。臨界面r_c(λ)を差し引いた温度方向と、無次元結合で流れを記述すると構造が明確になる。

導出：殻積分の係数からβ関数へ

\(b=e^{d\ell}\)の薄い殻を考え、\(r\)が十分小さいとする。4次元では

\[\int_{\Lambda e^{-d\ell}<|k|<\Lambda}\frac{d^4k}{(2\pi)^4}\frac1{k^4}=\frac1{8\pi^2}\,d\ell.\]

三つの運動量チャネルと対称因子\(1/2\)により、四次結合は\(\delta\lambda=-3\lambda^2d\ell/(16\pi^2)\)だけ変わる。\(d=4-\varepsilon\)では、再尺度化による\(+\varepsilon\lambda\)を加える。

\[\frac{d\lambda}{d\ell}=\varepsilon\lambda-\frac{3\lambda^2}{16\pi^2}+\cdots.\]

質量のtadpoleには切断に依存する加法的な項が含まれる。この項を臨界面\(r_c(\lambda)\)へ組み込み、\(t\propto r-r_c(\lambda)\)を用いて線形化すると、臨界面から離れる速さを表す指数\(y_t\)が得られる。

3-6 くりこみ群の流れ

原著 印刷pp.72–80 / 提供PDF pp.82–90

\[g \equiv \lambda \mu ^{-\varepsilon }/(16\pi ^{2}),\text{　} \varepsilon = 4-d\]
\[dg/d\ell = \varepsilon g - 3g^{2} + O(g^{3}),\text{　} g* = \varepsilon /3 + O(\varepsilon ^{2})\]

ここでは単一実スカラー場の慣用的な規格化を採る。ε > 0が十分小さいとき、Gaussian点ではgが有効であり、g*では結合方向が長距離に対して安定になる。これがWilson–Fisher固定点である。温度方向は依然として有効なので、臨界点へ到達するにはその調整が必要になる。

次元長距離の四次相互作用臨界点での含意
d > 4非有効Gaussian型の主要指数
d = 4中立的。正の弱結合はゆっくり減衰べき則に対数補正
d = 4−εGaussian点で有効弱結合の非自明固定点
\[y_{t} = 2 - \varepsilon /3 + O(\varepsilon ^{2}),\text{　} \omega = \varepsilon + O(\varepsilon ^{2})\]

ω > 0は、結合方向の非有効なずれがb^(−ω)で減る補正指数である。有限個の結合だけを追う計算が有効になるのは、捨てた項の累積効果を小さく抑えられる領域に限られる。原著はこの点を繰り返し検討している。

読み方・注意

ε = 1と代入するだけで3次元の精密値が得られるわけではない。ε展開は制御された小εの計算であり、低次の式の外挿には限界がある。

計算例：結合方向の流れを解く
\[\frac{dg}{d\ell}=\varepsilon g-3g^2,\qquad g(\ell)=\frac{g_*}{1+(g_*/g_0-1)e^{-\varepsilon\ell}},\quad g_*=\frac\varepsilon3.\]

\(\varepsilon>0\)、\(g_0>0\)の弱結合領域では、結合は\(g_*\)へ近づく。固定点近傍で\(g=g_*+\delta g\)とすると\(d\delta g/d\ell=-\varepsilon\delta g+\cdots\)となる。

\[\begin{pmatrix}t'\\ \delta g'\end{pmatrix}\simeq\begin{pmatrix}b^{y_t}&0\\0&b^{-\omega}\end{pmatrix}\begin{pmatrix}t\\\delta g\end{pmatrix}.\]

実際の質量と結合の座標では混合項が現れる。固有方向を選ぶとは、その混合を線形の範囲で対角化することに対応する。臨界面は一般に曲がっているので、単純に裸の質量だけをゼロへ合わせても固定点へ向かうとは限らない。

\(\varepsilon=0\)では\(g(\ell)=g_0/(1+3g_0\ell)\)。固定点への接近が指数関数から\(1/\ell\)へ遅くなることが、上部臨界次元の特徴である。

3-7 臨界現象の解析

原著 印刷pp.80–87 / 提供PDF pp.90–97

温度方向の増幅と脱出尺度

\[t_{n} \simeq b^{nyt} t,\text{　} |t_{n*}| \simeq 1\]
\[\xi \propto b^{n*} \propto |t|^{-1/yt},\text{　} \nu = 1/y_{t}\]

初期値が臨界面に近いほど、軌道は固定点近傍を長く通る。そこでの反復回数n*を評価し、相関距離が1程度になる尺度まで変換した理論から元へ戻す。これが、長距離の難問を比較的扱いやすい有限相関距離の問題へ移す仕組みである。

場の次元と磁化率

\[\Delta _{\varphi } = (d-2+\eta )/2,\text{　} G_{c}(x) \propto |x|^{-2\Delta \varphi }\]
\[\chi \propto \xi ^{2-\eta },\text{　} \gamma = \nu (2-\eta )\]

磁化率は2点相関の空間積分だから、距離ξまで積分するとξ^(2−η)が現れる。場に共役な外場の指数はy_h = d−Δ_φ。この関係から他の指数も定まる。

\[\beta _{mag} = \nu (d-2+\eta )/2,\text{　} \delta = (d+2-\eta )/(d-2+\eta )\]
\[\alpha = 2-d\nu \text{　　}(\text{通常のハイパースケーリングが成立する場合})\]

単一実スカラー場のε展開

\[\nu = \tfrac12 + \varepsilon /12 + O(\varepsilon ^{2}),\text{　} \gamma = 1 + \varepsilon /6 + O(\varepsilon ^{2})\]
\[\beta _{mag} = \tfrac12 - \varepsilon /6 + O(\varepsilon ^{2}),\text{　} \eta = \varepsilon ^{2}/54 + O(\varepsilon ^{3})\]

d > 4では四次結合が「危険な非有効変数」になり得るため、Gaussian指数へハイパースケーリングを機械的に適用できない。d = 4の単一成分・弱結合系では、対称相からt → 0⁺でξ ∝ t^(−1/2)[log(1/t)]^(1/6)、χ ∝ t^(−1)[log(1/t)]^(1/3)という主要な対数補正が付く。

読み方・注意

指数関係には成立条件がある。主要なべき指数、対数補正、非普遍的な振幅を分けて読む。

導出：脱出尺度と非普遍的な振幅

\(b^{n_*y_t}|t|\simeq c\)という条件で脱出回数を選ぶ。\(c\)は臨界領域の外で計算が容易になる任意の定数である。

\[n_*=-\frac{\log|t|}{y_t\log b}+O(1).\]

有限の\(O(1)\)の差は相関距離の振幅を変えるが、\(\log|t|\)の係数は変えない。だから臨界指数は普遍的であっても、\(\xi=A_\pm |t|^{-\nu}\)の振幅\(A_\pm\)自体は通常、微視的な規格化に依存する。

\[\chi\sim\int_0^\xi dr\,r^{d-1}r^{-(d-2+\eta)}\sim\xi^{2-\eta}.\]

この積分は\(\gamma=\nu(2-\eta)\)の直観的な導出になる。短距離の寄与は解析的な背景項を作り、特異性の主要部分は大きい距離から生じる。

非有効方向のずれが\(b^{-\omega}\)で減るなら、熱力学量には\(|t|^{\omega\nu}\)型の補正が現れる。有限サイズの数値計算では、相関距離だけでなく系の大きさも新しい尺度として入る。

3-8 厳密なくりこみ群

原著 印刷pp.87–94 / 提供PDF pp.97–104

多スケール分解

\[C = \sum _{j\ge 0} C_{j},\text{　} \varphi = \sum _{j\ge 0} \zeta _{j},\text{　} \langle \zeta _{i}\zeta _{j}\rangle = \delta _{ij}C_{j}\]

Gaussian共分散を尺度ごとの寄与に分け、独立な揺らぎを順に積分する。一段ごとの積分では、局所的な有効結合の変化と、残りの相互作用を分離する。残りが小さいというだけでなく、適切なノルムで次の反復でも小さく保たれることを示す必要がある。

小振幅と大振幅を同時に扱う

場が小さい領域では摂動的な展開を使える。しかし場の積分は全実数に及ぶため、大振幅領域を無視することはできない。四次項の安定性や確率的な抑制を用い、展開が直接使えない領域を別の評価で抑える。さらに体積やスケール数が増えても誤差定数が破綻しないことが重要になる。

追う量必要な制御
有効結合固定点と臨界面の近くに軌道を保つ
非有効な残余相互作用反復後も小さく、蓄積で主項を壊さない
大振幅の場積分の安定性と尾部の抑制
観測量と極限相関関数の評価、体積・臨界極限の整合

原著が紹介する結果と限界

Gawedzki–Kupiainenらの方法により、特に4次元の弱いφ⁴相互作用について、Gaussian点へゆっくり近づく流れが厳密に解析される。無秩序相へ脱出する軌道の制御と合わせることで、主要な対数補正を伴う臨界現象を基礎づける。

一方、同じ弱結合の議論で通常の3次元模型のWilson–Fisher点まで解けるわけではない。原著は「固定点が存在すると期待する」ことと「その近傍と吸引域を数学的に制御した」ことを区別している。

読み方・注意

厳密化の価値は数値を少し改善することだけではない。有限次数の近似が、どの仮定とどの範囲で正しいのかを明確にする点にある。

反復で残余を小さく保つ見積り

局所的な少数の結合を\(g_j\)、残余相互作用を\(K_j\)とする。厳密化では、例えば次のような収縮と発生項の評価を目指す。これは方法を示す模式式であり、原著の特定のノルム評価そのものではない。

\[\|K_{j+1}\|\le q\|K_j\|+C|g_j|^p,\qquad 0<q<1.\]
\[\|K_n\|\le q^n\|K_0\|+C\sum_{j=0}^{n-1}q^{n-1-j}|g_j|^p.\]

\(g_j\)の大きさも同時に制御できれば、捨てた相互作用が反復で無制限に増えることを防げる。証明では局所性、大振幅の場、体積依存、観測量を含むさらに詳しい評価が必要になる。

「非有効だから消える」という短い説明は、このような一様な評価を期待する動機であり、評価自体の代わりにはならない。
