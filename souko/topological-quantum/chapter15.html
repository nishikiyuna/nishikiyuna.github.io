Simon『Topological Quantum』第15章に対応 第15章 ツイスト

この章の概要 第2章で、リボンにできたカール（輪）を引き絞ると、リボンが自分の軸のまわりに1回ねじれた状態になることを見た。 時間を縦方向にとれば、これは粒子がその場で \(2\pi\) 自転する過程である。 本章では、このねじれを取り除く代償として現れる位相——ツイスト因子 \(\theta_a\)——を ダイアグラム代数の言葉で正式に定義し、第13章の \(R\) 行列との関係を3通り導く。 最後のものがリボン恒等式で、ゲージによらない関係式として以後の章（特に第17章の \(S\) 行列・\(T\) 行列）で繰り返し使う。 短い章だが、\(d_a<0\) の理論で \(\theta_a\) の符号が規約に依存するという落とし穴も含むので、定義と符号の扱いを丁寧に押さえたい。
章内目次

\(\theta\) と \(R\) の関係Relations between \(\theta\) and \(R\)

ツイスト因子の定義

ダイアグラムではリボンそのものは描かず、黒板フレーミング (blackboard framing)（リボンが常に紙面に平らに寝ているとみなす規約、第2章）を使う。 この規約のもとでは、リボンの1回ねじれは、線が自分自身と1回交差して小さな輪を作る「カール」として描かれる。

定義（ツイスト因子） 粒子種 \(a\) の線にできたカールを取り除いてまっすぐな線にすると、ダイアグラムの値は位相因子 \(\theta_a\) だけ変わる： \[ (\text{カールのある } a \text{ の線}) \;=\; \theta_a \,(\text{まっすぐな } a \text{ の線}) . \] カールが線の右側にあっても左側にあっても、交差の上下（カイラリティ）が同じなら同じ \(\theta_a\) を与える。 交差の上下を入れ替えた鏡像のカールは \(\theta_a^*\) を与える。この \(\theta_a\) をツイスト因子 (twist factor) と呼ぶ。

鏡像が複素共役になるのは、第12章のエルミート共役の原理（ダイアグラムを水平軸で反転し、矢印の向きを保つように付け替えると振幅が複素共役になる）による。 これを使うと次の基本性質が従う。

結果（ツイスト因子の基本性質）
  • \(\theta_a\) は絶対値1の複素数である：\(|\theta_a|=1\)。
  • 反粒子と同じ値をもつ：\(\theta_a=\theta_{\bar a}\)。
  • 真空は \(\theta_I=1\)。
証明の概略 互いに逆向きのカールを1つずつもつ線を考える。2つのカールを順に外すと \(\theta_a\theta_a^*\) 倍のまっすぐな線になる。 一方、同じダイアグラムは第13章で許された変形だけでまっすぐな線に直接変形できる。よって \(\theta_a\theta_a^*=1\)。 \(\theta_a=\theta_{\bar a}\) も同様に、\(a\) のカールを幾何学的に変形すると \(\bar a\) のカールとして読めることから従う。

位相スピンとスピン統計

ツイスト因子は位相スピン (topological spin)（共形場理論の言葉では共形スケーリング次元）\(h_a\) を使って

\[ \theta_a = \ee^{2\pi \ii h_a} \]

と書く。これは量子力学でスピン \(\hat S\) の粒子を \(2\pi\) 回転したときに得る位相 \(\ee^{2\pi\ii \hat S}\)（\(\hbar=1\)）と同じ形であり、真空は \(h_I=0\) である。 多くの位相的な量は \(\theta_a\) だけ、すなわち \(h_a\) の小数部分 \(h_a \bmod 1\) だけで決まる。

スピン統計定理（第2章）により、ツイスト因子は同種粒子2個の交換の位相と結びついている。 \(h_a\) が整数なら \(\theta_a=1\) でボソン、半奇数なら \(\theta_a=-1\) でフェルミオンであり、エニオンはその中間を埋める。

注意（記号 \(\theta\) と \(\vartheta\)） 第3〜5章では2個のエニオンの交換の位相を \(\ee^{\ii\vartheta}\) と書いた。 本章の \(\theta_a\) はそれ自体が位相因子であり、可換エニオンでは \(\theta=\ee^{\ii\vartheta}\) の関係にある。角度と位相因子を混同しないこと。

関係その1：カールを \(R\) 行列で評価する

カールは「線が自分自身と交差したもの」なので、\(R\) 行列で評価できる。 カールの付け根に完全性関係（第14章）を挿入して \(a\) と \(a\) を融合チャネル \(c\) に分解し、交差を \(R^{aa}_c\) で外し、残った泡を潰すと

\[ \theta_a = \sum_c \frac{d_c}{d_a}\, R^{aa}_c \]

を得る（\(N_{aa}^c\) が 0 か 1 の場合）。和は \(a\times a\) に現れる \(c\) にわたる。 \(R^{ab}_c\) は一般にゲージに依存するが、\(\theta_a\) と \(R^{aa}_c\) はゲージ不変である。

可換な理論では \(a\times a\) の融合先がただ1つで \(d_a=d_c=1\) だから、

\[ \theta_a = R^{aa}_{a\times a} \qquad (\text{可換エニオン}) \]

となり、「交換の位相 = 自転の位相」というスピン統計の関係そのものになる。

例（Fibonacci エニオン） Fibonacci 理論のツイスト因子は \(\theta_\tau=\ee^{\pm 4\pi\ii/5}\)（符号は右手型・左手型に対応）である。 第10章の \(R^{\tau\tau}_I\)、\(R^{\tau\tau}_\tau\) と \(d_\tau=\phi\)（黄金比）を式 に代入すると、この値が再現される。原書の演習でこの確認を扱う。

関係その2：真空チャネルの \(R\)

横向きに寝たカール（\(a\) と \(\bar a\) が対生成されて交差し、そのまま続いていく形）は、真空チャネルの \(R\) 行列 \(R^{a\bar a}_I\) で直接評価できる。 このカールは \(\theta_a^*\) を与えるカールに似ているが、厳密には同じではない。 縦向きのカールに直すには線にジグザグを1つ入れる必要があり、そのとき第14章のジグザグ因子 \(\epsilon_a\) が掛かる。結果は

\[ R^{a\bar a}_I = \epsilon_a\, \theta_a^* . \]

アイソトピー不変な理論では \(\epsilon_a=1\) に選んであるので、\(R^{a\bar a}_I=\theta_a^*\) である。

注意（\(d_a<0\) のときの \(\theta_a\) の符号） 第14章の「Option B」（\(d_a<0\) を許す非ユニタリな評価で、ユニタリな理論を表す方式）では、カールを外すときにキャップも1つ消えるため、 \[ \theta_a^{(d<0,\ \epsilon=+)} = -\,\theta_a^{(d>0,\ \epsilon=-)} \] と符号が変わる。式 はこの符号も正しく与え、\(\theta_a^{\text{非ユニタリ}}=\sgn(d_a)\,\theta_a^{\text{ユニタリ}}\) となる。 ジグザグ位相 \(\epsilon_a\) の負号をループの重み \(d_a\) に押し付けると、その分 \(\theta_a\) の符号が変わる、ということである。 一方 \(R^{a\bar a}_I\) は Option A でも Option B でも同じ値をとる。 混乱を避けたいときは、\(\theta_a\) の代わりに \(R^{a\bar a}_I\) を引用するのが安全である。

関係その3：リボン恒等式

定理（リボン恒等式） \(a\) と \(b\) が \(c\) に融合するとき、
\[ R^{ba}_c\, R^{ab}_c = \frac{\theta_c}{\theta_a\,\theta_b} . \]
左辺は \(a\) と \(b\) を融合チャネル \(c\) のもとで互いに1周させる（2回交換する）位相であり、この等式はゲージ不変である。
導出の考え方 \(c\) から \(a,b\) に分岐する頂点の上で、\(a\) と \(b\) の線を2回交差させたダイアグラムを考える。 \(R\) 行列を2回使えば \(R^{ba}_cR^{ab}_c\) 倍の単純な頂点になる。 一方、リボンとして見ると、2本の枝を互いに1周巻きつけた状態は、 「幹 \(c\) のリボンを1回ねじり、枝 \(a\) と \(b\) をそれぞれ逆向きに1回ねじった状態」へ連続的に変形できる（リボンを引き絞ると見える）。 幹のねじれが \(\theta_c\)、枝の逆ねじれが \(\theta_a^*=1/\theta_a\) と \(\theta_b^*=1/\theta_b\) を与えるので、右辺が得られる。

リボン恒等式は、交換の統計（\(R\)）が自転の位相（\(\theta\)）だけで決まることを示しており、 融合則とツイスト因子から \(S\) 行列を計算する公式（第17章）の出発点になる。 簡単な応用として、可換エニオンでは \(a\times a\) のツイスト因子が \(\theta_{a\times a}=(\theta_a)^4\)、 より一般に \(n\) 個の融合で \((\theta_a)^{n^2}\) となる（式 と合わせて導ける。原書の演習）。 これは第4章で見た「電荷-磁束複合体を \(n\) 個束ねると統計位相が \(n^2\) 倍になる」ことと一致する。 また、積理論 \(T_1\times T_2\) の粒子 \((a,\alpha)\) のツイスト因子は各因子の積 \(\theta_a\theta_\alpha\) である。

付録：融合多重度が大きい場合Appendix: Higher Fusion Multiplicities

融合多重度 \(N_{ab}^c>1\) のとき、頂点は添字 \(\mu\in\{1,\dots,N_{ab}^c\}\) をもち、\(R^{ab}_c\) はその添字についての行列 \([R^{ab}_c]_{\mu\nu}\) になる。 このとき式 はトレースに置き換わり、

\[ \theta_a = \sum_{c,\mu} \frac{d_c}{d_a}\,[R^{aa}_c]_{\mu\mu} , \]

リボン恒等式 は行列の積の形

\[ \sum_\nu [R^{ba}_c]_{\mu\nu}\,[R^{ab}_c]_{\nu\lambda} = \frac{\theta_c}{\theta_a\theta_b}\,\delta_{\mu\lambda} \]

になる。2回の交換は多重度の添字について単位行列に比例する、という主張である。

第15章のまとめ
  • ツイスト因子 \(\theta_a\) は、\(a\) の線のカール（リボンの \(2\pi\) ねじれ）を取り除くときに出る位相である。鏡像のカールは \(\theta_a^*\)。
  • \(|\theta_a|=1\)、\(\theta_a=\theta_{\bar a}\)、\(\theta_I=1\)。位相スピン \(h_a\) とは \(\theta_a=\ee^{2\pi\ii h_a}\) で結ばれる。
  • \(R\) 行列との関係は3つ：\(\theta_a=\sum_c (d_c/d_a)R^{aa}_c\)、\(R^{a\bar a}_I=\epsilon_a\theta_a^*\)、リボン恒等式 \(R^{ba}_cR^{ab}_c=\theta_c/(\theta_a\theta_b)\)。
  • \(d_a<0\) を使う規約では \(\theta_a\) の符号が変わる。曖昧さのない \(R^{a\bar a}_I\) を引用すると安全である。
