Simon『Topological Quantum』第36章に対応 第36章 エニオンを入れ替える対称性

この章の概要 TQFT の中には、エニオンの種類を入れ替えても理論が変わらないものがある。典型例はトーリック符号の \(e\leftrightarrow m\) である。 本章では、これを \(S\) 行列・\(T\) 行列を保つ置換行列として定義し、そのような対称性の対称性欠陥（周りを回るとエニオンの種類が入れ替わる点）を考える。 トーリック符号を \(e\) と \(m\) の区別が見えない対称な形に書き直すと、格子転位が対称性欠陥になり、1つの転位が Majorana ゼロモード（半分の量子ビット）を運ぶことがわかる。 最後に、対称性とエニオンの両方をもつ SET 相の一般的な見取り図を述べる（原書では Medium Material）。 第35章の SPT の議論（対称性欠陥・ゲージ化）の続きである。
章内目次

エニオンの置換対称性とは

TQFT の中にはエニオンの置換に対する対称性をもつものがある。これは一般的ではないが、あるときには特別な性質をもつので議論する価値がある。 エニオンを入れ替える対称性は、模型の微視的自由度の性質とは無関係に生じる「創発的」な対称性という点で特殊である。微視的なハミルトニアンにはまったく対称性がなくても、その基底状態として生じる TQFT が励起の置換対称性をもつことがありうる。 （ここで扱うのはユニタリな対称性だけで、時間反転を含む反ユニタリな対称性は扱わない。）

トーリック符号がよい例である。第28章の融合表で \(m\) と \(e\) を入れ替えても融合表は正しいままであり、また \(S\)・\(T\) 行列（第28章）の2行目・2列目は \(e\)、3行目・3列目は \(m\) に対応するが、2行3行・2列3列を入れ替えても行列は変わらない。 つまり、どちらを \(e\)、どちらを \(m\) と呼ぶかは問題にならない。

定義（エニオンの置換対称性） モジュラーな \(S\) 行列と \(T\) 行列（第17章）に対し、置換行列 \(P\)（\(P^TP=PP^T=1\) で、各行・各列にちょうど1つだけ 1 があり他は 0）が
\[ P S P^T = S,\qquad P T P^T = T \]
を満たすとき、その理論はエニオンを入れ替える対称性をもつという。 1つの TQFT に対して条件を満たす \(P\) は複数ありうる（自明な恒等行列も含む）。そのような \(P\) 全体は群をなし、エニオン置換群 (anyon permutation group) と呼ばれる（原書の演習 36.2）。
直観（なぜ偶然ではないのか） トーリック符号がこの対称性をもつのは、特殊な模型だからではない。第25章（§25.4）で、トーリック符号がより複雑な親理論（Ising\(\times\)Ising）から、あるボソンを凝縮させて得られることを見た。 その過程で親理論の粒子が2つの粒子に分裂し、結果はこの2つについて対称になる。一般にこれは次のように言える。
  • 親理論からシンプルカレントのボソンが凝縮し、分裂が起きると、凝縮後の理論はエニオンの置換対称性をもつ。
  • 逆に、エニオンの置換対称性をもつ理論は、常に「分裂を伴う凝縮の結果」とみなせる。

エニオン置換対称性の対称性欠陥Symmetry Defects of Anyon-Permuting Symmetry

第35章（§35.4.1）で述べたとおり、対称性をもつ任意の系で、1点の周りで対称性の作用によって波動関数をねじる（ねじれた境界条件を課す）ことで対称性欠陥を作れる。 第35章では \(\Z_2\) の微視的変数を \(\Z_2\) の作用でねじった。ここでは、エニオン置換対称性の対称性欠陥を考える。 それは2次元系の中の1点で、粒子をその点の周りに引きずると、粒子の種類が \(P\)（式 のうちの1つ）で変わる、というものである。 トーリック符号では \(m\) 粒子が欠陥を1周すると \(e\) 粒子に変わる（逆も同様）。つまり \(e\) と \(m\) が「入れ替わった」。 2種類の励起は局所的には区別できるが、大域的には区別できない（欠陥を回ると互いに変わるため）。

この種の対称性欠陥は通常の TQFT の構造には含まれず、\(G\)-交差拡大 (\(G\)-crossed extension)（\(G\) は対称性の群）という数学的構造の中に含まれる。 SPT の場合と同様、欠陥そのものもエニオンのような性質をもつものとして扱える。詳細は Barkeshli ら [2019] を参照されたい。

トーリック符号の対称な形Symmetric Form of the Toric Code

トーリック符号のエニオン置換対称性をより明示的にする。第27章・第28章のトーリック符号のハミルトニアンの各項（スタビライザー）は、頂点演算子と、プラケット演算子であった： \[ V_\alpha=\prod_{i\in\text{頂点 }\alpha}\sigma^z_{(i)},\qquad P_\beta=\prod_{i\in\text{プラケット }\beta}\sigma^x_{(i)} . \] \(V_\alpha\) の破れが電気的粒子 \(e\)、\(P_\beta\) の破れが磁気的粒子 \(m\) である。 従来の描き方では2種類の項は大きく異なって見える。

記法の変更だけで見かけを対称にしていく。

  1. 参照線を斜めに引く。 物理的なスピンもハミルトニアンの項も変えず、格子を菱形（ダイヤモンド）のタイル張りとして描き直す。すると頂点演算子（緑の菱形）もプラケット演算子（ピンクの菱形）も、菱形1つに作用する形になる。ただし緑の菱形では \(\sigma^z\) の4個の積、ピンクの菱形では \(\sigma^x\) の4個の積という違いがまだある。
  2. 緑の菱形の東と西の角にあるスピンにユニタリ変換をかける。 \(y\) 軸まわりの \(\pi/2\) 回転で、 \[ \sigma^x\to\sigma^z,\qquad \sigma^z\to-\sigma^x,\qquad \sigma^y\to\sigma^y . \]

この変換の後、頂点演算子は「菱形の北と南の \(\sigma^z\) 2個と、東と西の \(\sigma^x\) 2個の積」に、プラケット演算子は「東と西の \(\sigma^x\) 2個と、北と南の \(\sigma^z\) 2個の積」になる。つまりすべての菱形で演算子が全く同じ形になる。

結果（トーリック符号の対称な形） トーリック符号のハミルトニアンは（Wen による形）
\[ H_{\text{toric code}}=-\frac{\Delta}{2}\sum_{\text{菱形 }q}\sigma^z_{q_N}\,\sigma^x_{q_E}\,\sigma^z_{q_S}\,\sigma^x_{q_W} \]
と書ける。\(q_N,q_S,q_E,q_W\) は菱形 \(q\) の北・南・東・西の角のスピンである。これは \(\Delta_v=\Delta_p=\Delta\) とした第28章のハミルトニアンとユニタリ変換だけ異なる。 すべての項が互いに可換であることは通常のトーリック符号と同様に確かめられる。

元は頂点とプラケットという2種類の項で、それらの破れを \(e\)、\(m\) と呼んでいた。いまはすべて同じ形の菱形になったが、緑の菱形が \(e\)、ピンクの菱形が \(m\) に対応していることには変わりがない。 \(e\) は対で生成・消滅でき、\(m\) も対で生成・消滅できる（基底状態から頂点にあるスピンに \(\sigma^x\) をかけると、その頂点の北と南の菱形に励起の対ができ、\(\sigma^z\) をかけると東と西の菱形に対ができ、\(\sigma^y=i\sigma^x\sigma^z\) は両方を行う）。 すべての菱形が同じに見えるので、どちらの集合を \(e\)、どちらを \(m\) と呼ぶかは単なる約束になっている。それでも、励起は2つの異なる部分格子（緑の菱形とピンクの菱形）に住む2種類があり、それぞれ同じ色の菱形の上だけを動く（1つの頂点を共有する同色の2つの菱形の間で生成・消滅・移動する）。 \(e\) と \(m\) に特別な名前を付ける理由はなくても、住む部分格子が違い、互いに対消滅できないという意味で両者は異なる。

補足（部分格子を区別できなくなる模型） 通常のトーリック符号から菱形に直した模型では、非自明なサイクルを辺に沿って歩くのに必要な歩数は常に偶数である。しかし、スピンの1行を取り除いて、非自明なサイクルを一周する歩数が奇数になる模型にも一般化できる（通常のトーリック符号からは得られない）。 その模型ではサイクルを一周すると部分格子が入れ替わるので、ピンクと緑の部分格子の大域的な区別がなくなる。これは §35.4.1 の反周期境界条件の状況に似ており、基底状態の縮退は4ではなく2になる。

トーリック符号の対称性欠陥Symmetry Defects in the Toric Code

対称な形では対称性欠陥を自然に考えられる。この描像では、格子の転位 (lattice dislocation) が対称性欠陥になる（Bombin による発見）。 励起は、ちょうど1つの頂点を共有する菱形の間を飛び移らなければならない。転位の周りに励起を動かし、北へ2歩、東へ2歩、南へ2歩、西へ2歩と進むと、元の菱形ではなく、局所的に定義した部分格子が反対の隣の菱形に戻ってくる。 したがって \(e\) から始めれば \(m\) になり、その逆も成り立つ。エニオンの置換が実現されている。転位は対称性欠陥である。

転位の位置のプラケットは頂点が4つではなく5つある。ハミルトニアンの規則は「北と南の頂点に \(\sigma^z\)、東と西の頂点に \(\sigma^x\)」だったが、5頂点のプラケットではこの規則を保ち、さらに余分な頂点（4価でなく3価の頂点）に \(\sigma^y\) を付ける。この項は \[ -\frac{\Delta}{2}\,\sigma^z_N\,\sigma^x_E\,\sigma^z_S\,\sigma^x_W\,\sigma^y_{\text{3価}} \] で、固有値は \(\pm1\) であり、他のプラケット演算子（式 ）とも可換である。したがって、解析的に解ける可換射影模型であることに変わりはない。

基底状態の縮退の数え上げ

トーラス上に通常のプラケットと何個かの転位を置いた系の基底状態の縮退を、§27.3 と同様に自由度を数えて求める。

  • 全プラケット項の積は常に \(+1\) である（第27章の拘束と類似）。転位のない格子では2つの部分格子が2つの異なる拘束を作るが、転位があると局所的な部分格子が他方へ入れ替わり、2つの部分格子の区別がないので拘束は1つだけになる。
  • スピン数を \(N\)、プラケットの総数を \(N_p\) とすると、転位の数 \(n\) は
    \[ \frac n2 = N-N_p \]
    を満たし（原書の演習 36.3。オイラー標数を用いる）、転位の個数が偶数であることを意味する。
  • \(N\) 個のスピン（量子ビット）から出発し、独立なプラケット演算子は \(N_p-1\) 個（拘束の分が \(-1\)）なので、すべてのプラケットを基底状態に置いても \(n/2+1\) 個の量子ビットが未確定のまま残る。転位の対ごとに未割り当ての量子ビットが1つ増える、すなわち基底状態の縮退が2倍になる。
結果（転位と Majorana ゼロモード） 各転位は量子ビットの半分に相当する自由度に結びついている。これは各転位が Majorana ゼロモードを束縛しているということである（Ising エニオンの Majorana ゼロモードについては第3, 9, 10 章および §8.2.2 を参照。局所的な演算子で、2つで量子ビットを構成する）。 転位自体がエニオン的な性質をもつ。

転位が Ising 理論の粒子のように見えるのは偶然ではない。トーリック符号の対称性は Ising\(\times\)Ising 理論からの凝縮の結果として生じるものとみなせた。 一般の凝縮の図式は次の3段からなる（原書の図 36.6）。

  • \(\mathcal A=\text{Ising}\times\text{Ising}\)：親理論。
  • \(\mathcal T=\)「トーリック符号の欠陥化 (defectization)」：\(\mathcal A\) から \(\mathcal T\) へは凝縮 (condense) で下り、\(\mathcal T\) から \(\mathcal A\) へはゲージ化 (gauge) で上がる。
  • \(\mathcal U=\)\(\Z_2\) 対称性をもつトーリック符号：\(\mathcal T\) から \(\mathcal U\) へは欠陥を閉じ込めて (confine) 下り、\(\mathcal U\) から \(\mathcal T\) へは欠陥を導入して (defectize) 上がる。

第25章の凝縮と違い、中間の \(\mathcal T\) 理論では、対称性欠陥は理論の境界だけでなくバルクに住むことができる。欠陥を含む理論の数学的構造が \(G\)-交差拡大である。 最も興味深い段階は \(\mathcal T\) から \(\mathcal A\) へ上がるところで、\(\Z_2\) 対称性をゲージ対称性に格上げして凝縮を「元に戻す」。これは §35.6 の議論と非常によく似ている。 なお、矢印をたどって上へ行った結果は一意とは限らない。最上段で \(\mathcal A=SU(2)_2\times SU(2)_2\) とすることもでき、そこからボソンを凝縮してもトーリック符号が得られる（原書の演習 25.3）。詳細は Barkeshli ら [2019] にある。

補足（実験） この模型（対称性欠陥つきのトーリック符号）の基底状態波動関数は、小規模な超伝導量子コンピュータで実際に作られている（Andersen ら, 2023; Xu ら, 2023）。

§36.3.1 より一般の対称性欠陥

格子転位は特に分かりやすい例だが、対称性欠陥をつくる模型は他にもあり、下地の格子の転位に結びつける必要はない。 対称性欠陥は抽象的に考えることもでき（Barkeshli ら）、格子欠陥なしで対称性欠陥をもつ具体的な玩具模型を構成することもできる（Heinrich ら、Mesaros–Ran、Cheng ら）。ここで述べた以上に少し複雑になるが、それほど複雑ではない。

対称性に富んだトポロジカル相Symmetry-Enriched Topological Phases

SPT 相（短距離エンタングル状態、第35章）にはエニオン励起がない。ただし、ゲージ化（§35.4〜35.6）でエニオンをもつ模型に関係づけることはできる。 対称性とエニオンの両方をもつ相も考えられ、これを SET 相 (symmetry-enriched topological phase) と呼ぶ（§35.1 で定義）。\(\Z_2\) 対称性をもつトーリック符号はその好例である。

一般の構図は次のとおりである。エニオン理論 \(\mathcal U\) が対称性をもつとき、対称性欠陥をつくり、その欠陥をゲージ化して親理論 \(\mathcal A\) を得る。 もとの理論 \(\mathcal U\) にエニオンがなく対称性だけなら、一般にそれは SPT 相（短距離エンタングル）であり、ゲージ化すると Dijkgraaf–Witten（ねじれ Kitaev）模型になる（§35.5〜35.6）。 より一般には、\(\mathcal U\) 理論自身がエニオンをもち、\(\mathcal T\) 理論として \(G\)-交差理論が得られ、それをゲージ化して \(\mathcal A\) のエニオン理論に至る。 （第35章のオンサイト対称性に対し、本章のトーリック符号の例では分かりやすさのために格子対称性を使ったが、一般的な場合はオンサイト対称性を考えるのがよい。） SET 相の一般的な構成は Heinrich ら、Mesaros–Ran、Cheng ら の原論文に詳しい。

補足（原書の演習・文献案内） 原書の演習では、トーリック符号の \(P\)（演習 36.1）、置換行列が群をなすこと（36.2）、転位の個数の関係式 （36.3）、\(\Z_N\) トーリック符号の転位が \(N\) 状態系を担い \(\Z_N\) パラフェルミオンに結びつくこと（36.4）、\(S_3\) 量子ダブルの置換対称性（36.5）を扱う。 文献案内では、Bombin [2010]（転位の詳細）、You–Wen [2012]（自由度の数え上げ、\(\Z_p\) トーリック符号への拡張）、Burnell [2018]（対称性・凝縮・分裂の関係）、Barkeshli ら [2019]（\(G\)-交差テンソル圏）、Lu–Vishwanath [2016]（K 行列による SET）が挙げられている。
第36章のまとめ
  • 置換行列 \(P\) が \(PSP^T=S\)、\(PTP^T=T\) を満たすとき、理論はエニオンを入れ替える対称性をもつ。トーリック符号の \(e\leftrightarrow m\) が例である。これは創発的な対称性で、条件を満たす \(P\) 全体は群をなす。
  • 置換対称性をもつ理論は、分裂を伴うシンプルカレントのボソン凝縮の結果とみなせる。逆に、そのような凝縮から得られる理論は置換対称性をもつ。
  • 対称性欠陥は、周りを回るとエニオンの種類が置換される点であり、\(G\)-交差拡大の構造で記述される。
  • トーリック符号は \(H=-\frac{\Delta}{2}\sum_q\sigma^z_N\sigma^x_E\sigma^z_S\sigma^x_W\) と対称な形に書ける。格子の転位が対称性欠陥になり、5頂点のプラケットには \(\sigma^y\) を加える。
  • 自由度の数え上げから、転位の数 \(n\) は偶数（\(n/2=N-N_p\)）で、転位1個あたり量子ビットの半分、すなわち Majorana ゼロモード1個を束縛する。
  • SET 相は対称性とエニオンをもつ相で、対称性欠陥を作り、ゲージ化して親のエニオン理論に至るという構図で理解される。
