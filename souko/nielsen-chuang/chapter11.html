この章の概要 本章は Part III（量子情報理論）の数学的土台を据える章である。 「情報の量」を測る基本量として、まず古典の Shannon エントロピーを 動機付けから導入する（§11.1）。 続いて相対エントロピー・条件付きエントロピー・相互情報量からデータ処理不等式まで、 古典情報理論の道具一式を証明付きで整備する（§11.2）。 続いてその量子版である von Neumann エントロピーを定義し、 Klein の不等式・劣加法性・三角不等式・凹性など基本性質を系統的に証明する（§11.3）。 最後に、量子情報理論で最も深く、最もよく使われる不等式である 強劣加法性を、Lieb の定理を出発点として証明し、その帰結を並べる（§11.4）。 本章はほとんど「不等式のカタログ」である。 しかし、ここで揃える不等式が第12章（データ圧縮・チャネル容量・エンタングルメント理論）の すべての定理の部品になる。 なお本書の慣例に従い、対数 \(\log\) はすべて底 2（単位はビット）、 自然対数は \(\ln\) と書く。

Shannon エントロピーShannon entropy

「情報の量」をどう測ればよいか。出発点となる直観は、 情報とは驚きの度合いである、というものだ。 明日も太陽が昇る、という知らせにはほとんど情報がない——ほぼ確実に起こることだからである。 一方「宝くじの1等が当たった」という知らせは莫大な情報を運ぶ——めったに起こらないからである。 つまり、事象 \(x\) が確率 \(p(x)\) で起こるとき、\(x\) が実際に起きたと知ったときの 「驚き」は \(p(x)\) の減少関数であるべきだ。

驚きの関数形は、次の2つの自然な要請でほぼ決まってしまう。 独立な2つの事象 \(x,y\)（同時確率 \(p(x)p(y)\)）をまとめて知ったときの驚きは 個々の驚きの和であってほしい（加法性）。 そして驚きは確率の連続関数であってほしい。 「積を和に変える連続関数」は対数しかないから、驚きの度合い（自己情報量）は \[ -\log p(x) \] と置くのが唯一の選択である（底の選択は単位の選択にすぎない。底 2 なら単位はビット）。 確率 \(1/2\) の事象を知ると 1 ビット、確率 \(1/2^{10}\) の事象なら 10 ビット、という勘定になる。

定義（Shannon エントロピー） 確率変数 \(X\) が値 \(x\) を確率 \(p(x)\) で取るとき、\(X\) の Shannon エントロピー (Shannon entropy) を、自己情報量の期待値 \[ H(X) \equiv H(p(x)) \equiv -\sum_x p(x)\log p(x) \] で定義する。エントロピーは個々の値のラベルにはよらず、確率分布 \(\{p(x)\}\) だけで決まる。 そこで分布を明示して \(H(p_1,\dots,p_n)\) とも書く。

\(p(x)=0\) の項については \(0\log 0 \equiv 0\) という規約を採用する。 これは場当たり的な約束ではなく、\(\lim_{x\to 0^+} x\log x = 0\) による連続的な拡張である （起こり得ない事象は、驚き自体は無限大でも「期待値への寄与」はゼロ、と読める）。 この規約により \(H\) は確率単体上の連続関数になる。

\(H(X)\) には表裏一体の2つの読み方がある。

  • 知る前の不確かさ：\(X\) の値を知る前に、我々がどれだけ「分かっていない」か。
  • 知った後の情報量：\(X\) の値を知ったとき、平均してどれだけの情報を得るか。

極端な場合で感覚を確かめる。確定した変数（ある値の確率が 1）では \(H = -1\log 1 = 0\)：不確かさはない。 公平なコインでは \(H = -\frac12\log\frac12 - \frac12\log\frac12 = 1\) ビット。 \(d\) 通りの値が等確率なら \(H = \log d\) で、これが最大値であることを §11.2.2 で証明する。

操作的な意味と公理的特徴づけ エントロピーの本当の正当化は、上のような発見法的議論ではなく操作的な定理にある。 Shannon のノイズなし符号化定理（§12.2 で量子版とともに扱う）によれば、 i.i.d. 情報源 \(X\) の出力 \(n\) 文字は、\(n\to\infty\) で \(nH(X)\) ビットまで圧縮でき、それ未満には圧縮できない。 すなわち \(H(X)\) は「\(X\) を蓄えるのに必要な物理資源の量」そのものである。 また、(i) 分布の連続関数、(ii) 一様分布で \(n\) について単調増加、 (iii) 選択を2段階に分けても値が整合する（グループ化の合成則）、 という要請だけから \(H\) の関数形が定数倍を除いて一意に決まることも知られている （Shannon による公理的特徴づけ）。本書ではこの一意性は使わないので証明は割愛し、 以下では定義から出発して性質を導いていく。

エントロピーの基本性質Basic properties of entropy

§11.2.1 二値エントロピー

最も基本的な例は2値の確率変数（コイン投げ）である。

定義（二値エントロピー） \[ H_2(p) \equiv -p\log p - (1-p)\log(1-p), \qquad 0\le p\le 1 \] を二値エントロピー (binary entropy) と呼ぶ（\(H_2(0)=H_2(1)=0\)）。 文脈から明らかなときは単に \(H(p)\) とも書く。

グラフから読み取れる（そして計算で確かめられる）性質をまとめる。

  • 対称性：\(H_2(p) = H_2(1-p)\)。0 と 1 のラベルの付け替えに対する不変性である。
  • 最大値：\(H_2'(p) = \log\frac{1-p}{p}\) は \(p=1/2\) でのみゼロになり、 \(H_2(1/2)=1\) が最大値。最も予測しにくいコインが最も情報を運ぶ。
  • 凹性（上に凸）： \[ H_2''(p) = -\frac{1}{p(1-p)\ln 2} < 0 \qquad (0 < p < 1) \] より \(H_2\) は狭義に凹である。凹性の意味を言葉で述べると 「表の出る確率が \(p\) のコインと \(q\) のコインを混ぜて使う（どちらを使ったか忘れる）と、 不確かさは平均以上に増える」： \(H_2(\lambda p + (1-\lambda)q) \ge \lambda H_2(p) + (1-\lambda)H_2(q)\)。 この「混合はエントロピーを平均以上に増やす」という構図は、 量子版の凹性（§11.3.5）でそのまま再登場する。

\(H_2\) は本書の残りで至るところに顔を出す （チャネル容量、エンタングルメント濃縮のレートなど）。以後は既知の関数として扱う。

§11.2.2 相対エントロピー

2つの分布の「隔たり」を測る量を導入する。これは距離の公理を満たさないが、 エントロピー関係の不等式をほとんど一手で生成する母体として絶大な威力を持つ。

定義（相対エントロピー） 同じ添字集合上の2つの確率分布 \(p(x), q(x)\) に対し、\(q\) に対する \(p\) の 相対エントロピー (relative entropy, Kullback–Leibler ダイバージェンス) を \[ H(p(x)\,\|\,q(x)) \equiv \sum_x p(x)\log\frac{p(x)}{q(x)} = -H(p(x)) - \sum_x p(x)\log q(x) \] で定義する。規約として \(0\log\frac{0}{q}\equiv 0\)、また \(p>0\) の点で \(q=0\) なら \(H(p\|q)\equiv+\infty\) とする。

直観としては「真の分布が \(p\) なのに、\(q\) だと思い込んで符号を設計したときに 1文字あたり余計に払うビット数」である。実際 \(-\sum_x p(x)\log q(x)\) は「\(q\) 用の最適符号（長さ \(-\log q(x)\)）」で \(p\) からの出力を符号化したときの平均長であり、そこから真の最適値 \(H(p)\) を引いたものが \(H(p\|q)\) に他ならない。余計なコストが負になるはずはない——それが次の不等式である。

定理（相対エントロピーの非負性；Gibbs の不等式） \[ H(p(x)\,\|\,q(x)) \ge 0 \] であり、等号は \(p(x)=q(x)\)（すべての \(x\)）のとき、かつそのときに限る。
証明 鍵は対数の凹性を接線で押さえる初等不等式 \[ \ln x \le x - 1 \qquad (x > 0),\quad \text{等号は } x=1 \text{ のみ} \] である（\(f(x)=x-1-\ln x\) は \(f(1)=0\)、\(f'(x)=1-1/x\) が \(x=1\) を境に負から正へ 転じるので \(x=1\) が最小点であることから従う。これは Jensen の不等式の最簡例でもある）。 底を 2 に直すと \(\log x \le (x-1)/\ln 2\)。これを \(x=q(x)/p(x)\) に使う。 \(p(x)>0\) の項だけ和を取れば十分で、 \[ -H(p\|q) = \sum_{x:\,p(x)>0} p(x)\log\frac{q(x)}{p(x)} \le \frac{1}{\ln 2}\sum_{x:\,p(x)>0} p(x)\Bigl(\frac{q(x)}{p(x)}-1\Bigr) = \frac{1}{\ln 2}\Bigl(\textstyle\sum_{x:\,p(x)>0} q(x) - 1\Bigr) \le 0 . \] 最後は \(\sum_{x:\,p(x)>0} q(x)\le \sum_x q(x) = 1\) を使った。 等号成立には、まず接線不等式の等号条件から \(p(x)>0\) なるすべての \(x\) で \(q(x)=p(x)\) が必要で、するとそれらの \(q(x)\) だけで和が 1 になるから、 残りの点では \(q(x)=0=p(x)\)。すなわち \(p=q\)。∎

この一つの不等式から、エントロピーの基本的な上界がすべて落ちてくる。

応用1：エントロピーの最大値 \(X\) の取りうる値が \(d\) 個のとき、\(q\) を一様分布 \(q(x)=1/d\) に取ると \[ 0 \le H(p\,\|\,\text{一様}) = -H(X) + \log d \qquad\Longrightarrow\qquad H(X) \le \log d , \] 等号は \(p\) が一様分布のとき、かつそのときに限る。 「何も知らない」状態が一番エントロピーが高い、という直観の定式化である。
応用2：劣加法性 組 \((X,Y)\) の結合エントロピーを \(H(X,Y)\equiv -\sum_{x,y}p(x,y)\log p(x,y)\) とする。 \(p=p(x,y)\)、\(q=p(x)p(y)\)（周辺分布の積）と取ると \[ 0 \le H\bigl(p(x,y)\,\|\,p(x)p(y)\bigr) = -H(X,Y) - \sum_{x,y}p(x,y)\bigl[\log p(x)+\log p(y)\bigr] = H(X) + H(Y) - H(X,Y). \] すなわち劣加法性 (subadditivity) \[ H(X,Y) \le H(X) + H(Y) \] が成り立ち、等号は \(X\) と \(Y\) が独立のとき、かつそのときに限る。 相関があるぶんだけ、全体の不確かさは部分の不確かさの和より小さい。 この差がまさに次項の相互情報量である。

§11.2.3 条件付きエントロピーと相互情報量

2変数になると「片方を知ったとき、もう片方にどれだけ不確かさが残るか」 「2変数はどれだけ情報を共有しているか」という問いが立てられる。

定義（条件付きエントロピー・相互情報量） \[ H(X|Y) \equiv H(X,Y) - H(Y) \] を \(Y\) を知ったもとでの \(X\) の条件付きエントロピー (conditional entropy)、 \[ I(X;Y) \equiv H(X) + H(Y) - H(X,Y) \] を \(X\) と \(Y\) の相互情報量 (mutual information) と呼ぶ。 定義から直ちに \(I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)\) であり、 \(I(X;Y)=I(Y;X)\)（対称性）も明らかである。

\(H(X|Y)\) の定義を「全体の不確かさから \(Y\) の分を差し引いた残り」と読んだが、 これが「\(Y\) の値ごとの \(X\) のエントロピーの平均」に一致することを確かめておく。 \(p(x|y)=p(x,y)/p(y)\) を使って \[ H(X,Y)-H(Y) = -\sum_{x,y}p(x,y)\log p(x,y) + \sum_{y}p(y)\log p(y) = -\sum_{x,y}p(x,y)\log\frac{p(x,y)}{p(y)} = \sum_y p(y)\,H(X|Y=y), \] ここで \(H(X|Y=y)\equiv-\sum_x p(x|y)\log p(x|y)\) は分布 \(p(\cdot|y)\) のエントロピーである。 各項が非負だから、直ちに次を得る： \[ H(X|Y) \ge 0 , \] 等号は \(Y\) の値から \(X\) の値が確定するとき。 この「あたりまえ」の不等式が量子では破れる（§11.4 冒頭）ことを 記憶に留めておいてほしい。古典と量子の分岐点のひとつである。

定義を移項した \[ H(X,Y) = H(Y) + H(X|Y) = H(X) + H(Y|X) \] は連鎖律 (chain rule) と呼ばれる：「組の不確かさ＝先に知る方の不確かさ＋残りの条件付き不確かさ」。 繰り返し適用すれば多変数版 \[ H(X_1,\dots,X_n) = \sum_{i=1}^{n} H(X_i\,|\,X_1,\dots,X_{i-1}) \] が帰納法で従う（各ステップで組 \((X_1,\dots,X_{i-1})\) をひとつの変数とみなせばよい）。

相互情報量の非負性は §11.2.2 応用2 で既に示した： \[ I(X;Y) = H\bigl(p(x,y)\,\|\,p(x)p(y)\bigr) \ge 0, \] 等号は独立のとき。これを \(I(X;Y)=H(X)-H(X|Y)\ge 0\) と読み替えると \[ H(X|Y) \le H(X) \] すなわち条件付けはエントロピーを減らす（余計な情報を知って不確かさが増えることはない）。 以上の量たちの関係は、集合の Venn 図の類推で整理するのが便利である。

最後に、次項で使う条件付き相互情報量を定義しておく： \[ I(X;Y|Z) \equiv H(X|Z) - H(X|Y,Z). \] 「\(Z\) を知った上で、さらに \(Y\) を知ることで減る \(X\) の不確かさ」である。これも非負である。 実際、条件付きエントロピーが \(z\) ごとの平均だったのと同様に \[ I(X;Y|Z) = \sum_z p(z)\, I(X;Y|Z=z) \] と書け（両辺を \(H(X|Z=z)-H(X|Y,Z=z)\) の平均として展開すれば一致する）、 各項は条件付き分布 \(p(x,y|z)\) に対する通常の相互情報量だから非負である。よって \[ I(X;Y|Z) \ge 0 \qquad\Longleftrightarrow\qquad H(X|Y,Z) \le H(X|Z). \]

§11.2.4 データ処理不等式

情報理論の教えのなかで最も「物理法則」らしいのが次の主張である： 一度失われた情報は、その後どんなに巧妙にデータを加工しても回復できない。 これを定式化するには、「加工」の連なりを表す言葉が要る。

定義（Markov 連鎖） 確率変数の列 \(X\to Y\to Z\) が Markov 連鎖 (Markov chain) であるとは、 \(Y\) を与えたとき \(Z\) が \(X\) と条件付き独立になること、すなわち \[ p(z\,|\,y,x) = p(z\,|\,y) \] が成り立つことをいう。典型例：\(X\) が元データ、\(Y=f(X)+\text{ノイズ}\) が観測値、 \(Z=g(Y)\) が観測値だけから計算した推定量。\(Z\) の作り方が 「\(Y\) だけを見て決める」ものである限り（決定的でも確率的でもよい）、 \(X\to Y\to Z\) は Markov 連鎖になる。
定理（データ処理不等式） \(X\to Y\to Z\) が Markov 連鎖ならば \[ H(X) \;\ge\; I(X;Y) \;\ge\; I(X;Z). \] 特に \(Z=g(Y)\)（決定的な後処理）なら常に \(I(X;Z)\le I(X;Y)\)： 後段の処理は \(X\) についての情報を増やせない。
証明 最初の不等式は \(I(X;Y)=H(X)-H(X|Y)\le H(X)\)（\(H(X|Y)\ge0\)）そのものである。 本体は第2の不等式である。まず、恒等式として成り立つ 相互情報量の連鎖律を確認する。定義を代入するだけで \[ I(X;Y,Z) = H(X)-H(X|Y,Z), \qquad I(X;Z) + I(X;Y|Z) = H(X)-H(X|Z) + H(X|Z)-H(X|Y,Z) \] の右辺同士が等しいから \[ I(X;Y,Z) = I(X;Z) + I(X;Y|Z) \] であり、\(Y\) と \(Z\) の役割を入れ替えれば \(I(X;Y,Z) = I(X;Y) + I(X;Z|Y)\) も成り立つ。2つの展開を等置して \[ I(X;Z) + I(X;Y|Z) = I(X;Y) + I(X;Z|Y). \] ここで Markov 性を使う。\(Y\) を与えると \(X\) と \(Z\) は条件付き独立だから、 各 \(y\) に対する相互情報量 \(I(X;Z|Y=y)\) はゼロ、よって \(I(X;Z|Y)=0\)。 一方 \(I(X;Y|Z)\ge 0\)（§11.2.3）。したがって \[ I(X;Z) \le I(X;Z) + I(X;Y|Z) = I(X;Y). \] ∎
補足
  • Markov 性 \(p(z|y,x)=p(z|y)\) は、Bayes 則を使うと \(p(x|y,z)=p(x|y)\) と同値であることが 確かめられる。つまり \(X\to Y\to Z\) なら \(Z\to Y\to X\) も Markov 連鎖であり （Markov 連鎖の反転）、同じ定理から \(I(Z;X)\le I(Z;Y)\)、すなわち パイプラインの下流は上流より多くを知らないという対称な結論も出る。
  • データ処理不等式は推定理論の限界（Fano の不等式と組んで誤り確率の下界を与える）や、 チャネルを継ぎ足しても容量が増えないことの証明などに使われる。 量子版——量子操作を繰り返すと状態についての情報が単調に劣化する——は 強劣加法性から従う（§11.4.2、および第12章）。

von Neumann エントロピーVon Neumann entropy

量子力学では、確率分布の役割を密度演算子 \(\rho\)（§2.4）が引き受ける。 Shannon エントロピーの \(p(x)\) を \(\rho\) に、和をトレースに置き換えるのが 量子版エントロピーである。

定義（von Neumann エントロピー） 密度演算子 \(\rho\) の von Neumann エントロピーを \[ S(\rho) \equiv -\tr(\rho\log\rho) \] で定義する。\(\rho\) のスペクトル分解を \(\rho=\sum_x \lambda_x\ketbra{x}{x}\) （\(\lambda_x\ge0,\ \sum\lambda_x=1\)、\(\{\ket x\}\) は正規直交）とすると \[ S(\rho) = -\sum_x \lambda_x\log\lambda_x = H(\lambda_1,\lambda_2,\dots), \] すなわち固有値の分布の Shannon エントロピーである。 ここでも \(0\log0\equiv0\) の規約を使う。系 \(A\) の状態 \(\rho_A\) のエントロピーを \(S(A)\)、合成系 \(AB\) の状態 \(\rho_{AB}\) のそれを \(S(A,B)\) あるいは \(S(AB)\) と略記する。
数学的準備：演算子の関数と凸性の言葉 本章で使う演算子計算をまとめておく。 エルミート演算子 \(A=\sum_i a_i\ketbra{i}{i}\) に対し、実関数 \(f\) の演算子版を スペクトル分解で定義する：\(f(A)\equiv\sum_i f(a_i)\ketbra{i}{i}\)。 したがって \(\tr f(A)=\sum_i f(a_i)\) であり、\(\rho\log\rho\) は固有値 0 の方向では \(0\log0=0\) として（連続極限で）定義される。 \(A\) と \(B\) が可換でないとき \(\log(AB)\ne\log A+\log B\) である点には常に注意が要る （本章の不等式の多くは、この非可換性をどう飼い慣らすかの技術である）。 また、演算子の組に対する関数 \(f(A,B)\) が同時凹 (jointly concave) であるとは、 \(0\le\lambda\le1\) と2組 \((A_1,B_1),(A_2,B_2)\) に対し \[ f\bigl(\lambda A_1+(1-\lambda)A_2,\ \lambda B_1+(1-\lambda)B_2\bigr) \ \ge\ \lambda f(A_1,B_1)+(1-\lambda)f(A_2,B_2) \] が成り立つことをいう（各引数ごとの凹性より真に強い）。 スカラーの Jensen の不等式（凹関数 \(f\) に対し \(\mathbb E[f(X)]\le f(\mathbb E[X])\)）は 既知とする。§11.4 の Lieb の定理がこの言葉で述べられる。

例
  • 純粋状態 \(\rho=\ketbra\psi\psi\)：固有値は \(1,0,\dots,0\) なので \(S=0\)。純粋状態は「量子的に完全に既知」の状態である。
  • 最大混合状態 \(\rho=I/d\)：固有値がすべて \(1/d\) なので \(S=\log d\)。 量子ビット（\(d=2\)）なら 1 ビット。これが最大値であることを §11.3.2 で示す。
  • 対角的な量子ビット \(\rho=p\ketbra00+(1-p)\ketbra11\)：\(S(\rho)=H_2(p)\)。 固有基底に乗ってしまえば von Neumann エントロピーは Shannon エントロピーに退化する。 量子固有の現象はすべて「非可換性」と「エンタングルメント」から来る。
  • Bell 状態の部分系：\(\ket{\beta_{00}}=(\ket{00}+\ket{11})/\sqrt2\) は純粋なので \(S(AB)=0\)。しかし部分トレースを取ると \(\rho_A=\tr_B\ketbra{\beta_{00}}{\beta_{00}}=I/2\) で \(S(A)=1\)。全体を完全に知っているのに部分は最大限に不確か—— 古典の \(H(X)\le H(X,Y)\) では決して起こらないことが量子では起こる。 エンタングルメントのエントロピー的な顔である。

§11.3.1 量子相対エントロピー

古典（§11.2.2）と同じく、不等式の生成源として相対エントロピーの量子版を先に用意する。

定義（量子相対エントロピー） 密度演算子 \(\rho,\sigma\) に対し \[ S(\rho\,\|\,\sigma) \equiv \tr(\rho\log\rho) - \tr(\rho\log\sigma). \] \(\rho\) の台（supp、固有値正の固有空間）が \(\sigma\) の台に含まれないときは \(S(\rho\|\sigma)\equiv+\infty\) とする（古典の \(p>0,\ q=0\) の場合に対応）。
定理（Klein の不等式） \[ S(\rho\,\|\,\sigma) \ge 0, \] 等号は \(\rho=\sigma\) のとき、かつそのときに限る。
証明

両者をスペクトル分解する： \(\rho=\sum_i p_i\ketbra{i}{i}\)、\(\sigma=\sum_j q_j\ketbra{j}{j}\) （それぞれ正規直交固有基底、\(+\infty\) の場合は不等式が自明なので \(q_j>0\) がすべての関与する \(j\) で成り立つ場合を考える）。定義に代入すると \[ S(\rho\|\sigma) = \sum_i p_i\log p_i - \sum_i \bra{i}\rho\log\sigma\ket{i} = \sum_i p_i\Bigl(\log p_i - \bra{i}\log\sigma\ket{i}\Bigr). \] ここで \(\log\sigma=\sum_j(\log q_j)\ketbra jj\) だから \[ \bra{i}\log\sigma\ket{i} = \sum_j P_{ij}\log q_j, \qquad P_{ij}\equiv|\braket{i}{j}|^2 . \] 行列 \(P_{ij}\) は非負で、\(\{\ket i\},\{\ket j\}\) がともに正規直交基底であることから \(\sum_j P_{ij}=1\) かつ \(\sum_i P_{ij}=1\)（二重確率行列）。 各 \(i\) を固定すると \(\{P_{ij}\}_j\) は確率分布なので、\(\log\) の凹性（Jensen の不等式）より \[ \sum_j P_{ij}\log q_j \ \le\ \log\Bigl(\sum_j P_{ij}q_j\Bigr) \equiv \log r_i, \qquad r_i \equiv \sum_j P_{ij}q_j = \bra{i}\sigma\ket{i}. \] したがって \[ S(\rho\|\sigma) \ \ge\ \sum_i p_i\log\frac{p_i}{r_i} = H(p\,\|\,r). \] ここで \(\{r_i\}\) は確率分布である：\(r_i\ge0\) かつ \(\sum_i r_i=\sum_j q_j\sum_i P_{ij}=\sum_j q_j=1\)（二重確率性を使った）。 よって Gibbs の不等式（§11.2.2）から \(H(p\|r)\ge0\)、すなわち \(S(\rho\|\sigma)\ge0\)。

等号条件を追う。等号には (a) 各 \(i\)（\(p_i>0\)）での Jensen の等号と (b) \(H(p\|r)=0\) すなわち \(p_i=r_i\) が必要である。 (a) の等号は、\(\log\) が狭義凹だから「\(P_{ij}\ne0\) なるすべての \(j\) で \(q_j\) が同一の値 （\(=r_i\)）」を意味する。すると \[ \sigma\ket{i} = \sum_j q_j\ketbra jj\,\ket{i} = \sum_{j:\,\braket ji\ne0} q_j\braket ji\,\ket{j} = r_i\sum_j \braket ji\,\ket{j} = r_i\ket{i}, \] つまり \(\ket i\) は \(\sigma\) の固有ベクトルで固有値 \(r_i=p_i\)（(b) を使った）。 \(p_i>0\) の固有ベクトルたちがこれを満たし、両者ともトレース 1 なので残りの部分も一致し、 \(\rho=\sigma\) が従う。逆に \(\rho=\sigma\) なら明らかに \(S(\rho\|\sigma)=0\)。∎

証明の構造を振り返ると、非可換性はすべて二重確率行列 \(P_{ij}=|\braket ij|^2\) に 吸収され、あとは古典の Gibbs の不等式に帰着した。 「固有基底のズレを二重確率行列で古典化する」のは量子情報でよく使う手筋である。

§11.3.2 エントロピーの基本性質

定理（von Neumann エントロピーの基本性質）
  1. \(S(\rho)\ge0\)。等号は \(\rho\) が純粋状態のとき、かつそのときに限る。
  2. \(d\) 次元の系で \(S(\rho)\le\log d\)。等号は \(\rho=I/d\) のとき、かつそのときに限る。
  3. ユニタリ不変性：\(S(U\rho U^\dagger)=S(\rho)\)。
  4. 合成系 \(AB\) が純粋状態なら \(S(A)=S(B)\)。
  5. 結合エントロピー定理：\(\{\ket i\}\) を系 \(B'\) の正規直交系、\(p_i\) を確率分布、 \(\rho_i\) を系 \(A\) の任意の状態として \[ S\Bigl(\sum_i p_i\,\rho_i\otimes\ketbra ii\Bigr) = H(p) + \sum_i p_i\,S(\rho_i). \] 特に \(S(\rho\otimes\sigma)=S(\rho)+S(\sigma)\)（加法性）。
証明

1. \(S(\rho)=H(\lambda)\) は固有値分布の Shannon エントロピーなので非負。 ゼロになるのは分布が確定的、すなわち固有値が \(1,0,\dots,0\) のときで、これは純粋状態を意味する。

2. Klein の不等式で \(\sigma=I/d\) と取る。\(\log(I/d)=-(\log d)\,I\) だから \[ 0 \le S(\rho\,\|\,I/d) = -S(\rho) - \tr\bigl(\rho\,(-\log d)I\bigr) = -S(\rho) + \log d . \] 等号条件も Klein のそれ（\(\rho=I/d\)）をそのまま引き継ぐ。 古典の応用1（§11.2.2）と一字一句同じ構造であることに注意。

3. \(U\rho U^\dagger\) は \(\rho\) と同じ固有値を持つ（固有ベクトルが \(U\ket x\) に回るだけ）。エントロピーは固有値だけの関数なので不変。 物理的には「可逆な時間発展は情報を失わない」ことの表現である。

4. 純粋状態 \(\ket\psi_{AB}\) の Schmidt 分解（§2.5）を使う： 正規直交系 \(\{\ket{a_k}\}\subset A\)、\(\{\ket{b_k}\}\subset B\) と非負実数 \(\sqrt{\lambda_k}\)（\(\sum_k\lambda_k=1\)）が存在して \[ \ket\psi = \sum_k \sqrt{\lambda_k}\,\ket{a_k}\ket{b_k}. \] 部分トレースを実行すると \[ \rho_A = \sum_k \lambda_k\ketbra{a_k}{a_k}, \qquad \rho_B = \sum_k \lambda_k\ketbra{b_k}{b_k} \] となり、両者は同一の固有値集合 \(\{\lambda_k\}\) を持つ。 よって \(S(A)=H(\lambda)=S(B)\)。Bell 状態の例（\(S(A)=S(B)=1\)）はこの特別な場合である。

5. \(\rho_i=\sum_j\lambda_i^{(j)}\ketbra{e_i^{(j)}}{e_i^{(j)}}\) と 各 \(\rho_i\) をスペクトル分解すると、 \[ \sum_i p_i\,\rho_i\otimes\ketbra ii = \sum_{i,j} p_i\lambda_i^{(j)}\;\ketbra{e_i^{(j)}}{e_i^{(j)}}\otimes\ketbra ii . \] 右辺に現れるベクトル \(\ket{e_i^{(j)}}\ket{i}\) たちは、第2因子の直交性のおかげで （\(i\) が異なれば自動的に直交するから）全体として正規直交系をなす。 つまりこれがスペクトル分解そのもので、固有値は \(\{p_i\lambda_i^{(j)}\}\)。よって \[ S = -\sum_{i,j}p_i\lambda_i^{(j)}\log\bigl(p_i\lambda_i^{(j)}\bigr) = -\sum_i p_i\log p_i\underbrace{\sum_j\lambda_i^{(j)}}_{=1} -\sum_i p_i\sum_j\lambda_i^{(j)}\log\lambda_i^{(j)} = H(p) + \sum_i p_i S(\rho_i). \] 加法性は、\(\sigma=\sum_i q_i\ketbra ii\)（固有分解）として \(\rho\otimes\sigma=\sum_i q_i\,\rho\otimes\ketbra ii\) に上式を適用すれば \(S(\rho\otimes\sigma)=H(q)+S(\rho)=S(\sigma)+S(\rho)\)。∎

性質 4 は見かけによらず深い。合成系が純粋である限り、 部分系 \(A,B\) の次元がどれほど違っても不確かさは等量である。 これは「純粋状態における部分系のエントロピーは、状態そのものの性質というより \(A\) と \(B\) の間のエンタングルメントの量である」ことを示唆する。 実際 \(S(A)\) は純粋状態のエンタングルメント測度（エンタングルメント・エントロピー）として 第12章で主役になる。

§11.3.3 射影測定はエントロピーを増やす

測定はエントロピーをどう変えるか。結果を読まずに射影測定を行う （非選択的測定：状態は各結果の混合になる）と、不確かさは必ず増える。

定理（射影測定によるエントロピー増大） \(\{P_i\}\) を完全な直交射影の族（\(P_iP_j=\delta_{ij}P_i\)、\(\sum_iP_i=I\)）とし、 測定後の状態を \[ \rho' = \sum_i P_i\,\rho\,P_i \] とすると \[ S(\rho') \ge S(\rho), \] 等号は \(\rho'=\rho\) のとき、かつそのときに限る。
証明 Klein の不等式を \(S(\rho\,\|\,\rho')\ge0\) の形で使う： \[ 0 \le S(\rho\,\|\,\rho') = -S(\rho) - \tr(\rho\log\rho'). \] あとは \(-\tr(\rho\log\rho')=S(\rho')\) を示せばよい。鍵は \(\rho'\) がすべての \(P_i\) と可換なことである。実際 \[ P_k\rho' = P_k\sum_iP_i\rho P_i = P_k\rho P_k = \sum_iP_i\rho P_i\,P_k = \rho'P_k \] （\(P_kP_i=\delta_{ki}P_k\) を2回使った）。可換なら関数計算も可換なので \([\log\rho',P_i]=0\)。これと \(\sum_iP_i=I\)、トレースの巡回性、\(P_i^2=P_i\) を使って \[ \tr(\rho\log\rho') = \sum_i\tr(P_i\,\rho\log\rho') = \sum_i\tr(P_i\,\rho\log\rho'\,P_i) = \sum_i\tr(P_i\,\rho\,P_i\log\rho') = \tr(\rho'\log\rho') = -S(\rho'). \] （2つ目の等号は \(\tr(P_iM)=\tr(P_iMP_i)\)、3つ目は \(\log\rho'\) を \(P_i\) と交換した。） 代入して \(0\le -S(\rho)+S(\rho')\)。等号は Klein の等号条件から \(\rho=\rho'\)。∎
注意：一般の測定では減ることもある この定理は射影測定に固有で、一般化測定（POVM とその測定演算子）では エントロピーが減りうる。極端な例：量子ビットの測定演算子を \(M_1=\ketbra00,\ M_2=\ketbra01\) と取る （\(M_1^\dagger M_1+M_2^\dagger M_2=\ketbra00+\ketbra11=I\) で正当な測定である）。 どんな入力 \(\rho\) に対しても測定後の非選択的状態は \[ \rho' = M_1\rho M_1^\dagger + M_2\rho M_2^\dagger = \bigl(\bra0\rho\ket0+\bra1\rho\ket1\bigr)\ketbra00 = \ketbra00 \] となり \(S(\rho')=0\le S(\rho)\)。系を「リセット」する操作は不確かさを捨てられる （そのぶん環境にエントロピーを押し付けている、と読むのが熱力学的に正しい）。

§11.3.4 劣加法性と三角不等式

2体系のエントロピーの上下の限界を確定する。上からの限界は古典と同じ形、 下からの限界は古典と似て非なる形になる。

定理（劣加法性） 合成系の任意の状態 \(\rho_{AB}\) に対し \[ S(A,B) \le S(A) + S(B), \] 等号は \(\rho_{AB}=\rho_A\otimes\rho_B\) のとき、かつそのときに限る。
証明 Klein の不等式で \(\rho=\rho_{AB}\)、\(\sigma=\rho_A\otimes\rho_B\) と取る。 テンソル積の対数は（両因子が可換に作用するので） \[ \log(\rho_A\otimes\rho_B) = (\log\rho_A)\otimes I_B + I_A\otimes(\log\rho_B) \] と分解する（スペクトル分解 \(\rho_A\otimes\rho_B=\sum_{k,l}\lambda_k\mu_l\, \ketbra{a_k}{a_k}\otimes\ketbra{b_l}{b_l}\) に \(\log(\lambda\mu)=\log\lambda+\log\mu\) を 適用すれば直ちに出る）。よって \[ \tr\bigl(\rho_{AB}\log(\rho_A\otimes\rho_B)\bigr) = \tr\bigl(\rho_{AB}(\log\rho_A\otimes I)\bigr) + \tr\bigl(\rho_{AB}(I\otimes\log\rho_B)\bigr) = \tr(\rho_A\log\rho_A) + \tr(\rho_B\log\rho_B), \] 最後の等号は部分トレースの定義（\(\tr(\rho_{AB}(M_A\otimes I))=\tr(\rho_AM_A)\)）による。 したがって \[ 0 \le S(\rho_{AB}\,\|\,\rho_A\otimes\rho_B) = -S(A,B) + S(A) + S(B), \] 等号は Klein の等号条件より \(\rho_{AB}=\rho_A\otimes\rho_B\)。∎

古典の劣加法性（§11.2.2 応用2）とまったく同じ論法である。 量子相互情報量を \[ I(A;B) \equiv S(A)+S(B)-S(A,B) = S(\rho_{AB}\,\|\,\rho_A\otimes\rho_B) \ge 0 \] と定義すれば、これが「\(AB\) 間の相関の総量」を測る非負量になることも同時に分かる。

下からの限界はどうか。古典では \(H(X,Y)\ge\max(H(X),H(Y))\)（部分は全体を超えない）だが、 量子では Bell 状態が \(S(AB)=0<1=S(A)\) を与えるのでこの形は偽である。 正しい下界は次で与えられる。

定理（三角不等式；Araki–Lieb の不等式） \[ S(A,B) \ \ge\ \bigl|S(A)-S(B)\bigr| . \]
証明 純粋化を使う。任意の \(\rho_{AB}\) に対し、参照系 \(R\) を導入して 合成系 \(ABR\) の純粋状態 \(\ket\psi_{ABR}\) で \(\tr_R\ketbra\psi\psi=\rho_{AB}\) と なるものが取れる（§2.5）。\(ABR\) が純粋であることから、性質 4（§11.3.2）を 分割 \((AB|R)\) と \((AR|B)\) に適用して \[ S(R) = S(A,B), \qquad S(A,R) = S(B). \] 劣加法性を系 \(A\) と \(R\) に使うと \[ S(B) = S(A,R) \le S(A) + S(R) = S(A) + S(A,B) \qquad\Longrightarrow\qquad S(A,B) \ge S(B) - S(A). \] \(A\) と \(B\) の役割を入れ替えれば \(S(A,B)\ge S(A)-S(B)\) も得られ、合わせて主張を得る。 ∎
純粋化という手筋 この証明は本章で繰り返し使う型の初出である： 足りない不等式は、系を純粋化して既知の不等式を別の分割に適用すると出てくる。 純粋状態では「どの分割で切っても両側のエントロピーが等しい」（性質 4）ため、 純粋化はエントロピーたちの間の「両替」を可能にする。 Bell 状態で三角不等式の等号（\(1=|1-0|\)…ではなく \(0=|1-1|\)）が成り立つことも 確かめられる：\(S(AB)=0\)、\(S(A)=S(B)=1\) で確かに \(0=|1-1|\)。

§11.3.5 エントロピーの凹性

状態を確率的に混ぜると不確かさは増える——ただし「どれを混ぜたか」の分だけ増え方には 上限もある（次項）。まず下からの評価、すなわち凹性を示す。

定理（凹性） 確率分布 \(\{p_i\}\) と状態 \(\{\rho_i\}\) に対し \[ S\Bigl(\sum_i p_i\rho_i\Bigr) \ \ge\ \sum_i p_i\,S(\rho_i), \] 等号は \(p_i>0\) なるすべての \(\rho_i\) が等しいとき、かつそのときに限る。
証明（補助系を使う） どの状態を混ぜたかを記録する補助系 \(B\)（正規直交基底 \(\{\ket i\}\)）を導入し、 合成状態 \[ \rho_{AB} \equiv \sum_i p_i\,\rho_i\otimes\ketbra ii \] を考える。各周辺状態は \[ \rho_A = \sum_i p_i\rho_i, \qquad \rho_B = \sum_i p_i\ketbra ii, \] であり、結合エントロピー定理（§11.3.2 性質 5）から \[ S(A,B) = H(p) + \sum_i p_iS(\rho_i), \qquad S(B) = H(p). \] 劣加法性 \(S(A,B)\le S(A)+S(B)\) に代入すると \[ H(p) + \sum_i p_iS(\rho_i) \ \le\ S\Bigl(\sum_i p_i\rho_i\Bigr) + H(p) \] となり、\(H(p)\) を消去すれば主張の不等式を得る。 等号は劣加法性の等号条件 \(\rho_{AB}=\rho_A\otimes\rho_B\)、すなわち \(\sum_ip_i\rho_i\otimes\ketbra ii=\rho_A\otimes\sum_ip_i\ketbra ii\) と同値で、 両辺の \(\ketbra ii\) 成分を比べると \(p_i\rho_i=p_i\rho_A\)、 つまり \(p_i>0\) なるすべての \(i\) で \(\rho_i=\rho_A\)（すべて同一）となる。∎

証明の発想を言葉にしておく：「混ぜて忘れる」ことによる不確かさの増加を測りたければ、 忘れる前の状態（ラベル付きの状態 \(\rho_{AB}\)）をあらわに作ってから、 ラベルを部分トレースで捨てればよい。 補助系にいったん情報を書き出すこの手法は、量子情報の証明技術の定番であり、 次項でも §11.4 でも使う。

§11.3.6 混合状態のエントロピーの上限

凹性と対になる上からの評価を示す。増え方の上限は「ラベルのエントロピー \(H(p)\)」である。

定理（混合のエントロピーの上界） \[ S\Bigl(\sum_i p_i\rho_i\Bigr) \ \le\ \sum_i p_i\,S(\rho_i) + H(p), \] 等号は \(\rho_i\) たちの台が互いに直交するとき、かつそのときに限る。
証明

ステップ1：純粋状態の混合の場合。 まず \(\rho=\sum_ip_i\ketbra{\psi_i}{\psi_i}\)（\(\ket{\psi_i}\) は正規化されているが 直交している必要はない）に対して \(S(\rho)\le H(p)\) を示す。 補助系 \(B\)（正規直交基底 \(\{\ket i\}\)）を使って純粋状態 \[ \ket{\Psi}_{AB} \equiv \sum_i \sqrt{p_i}\,\ket{\psi_i}_A\ket{i}_B \] を作る（\(\braket\Psi\Psi=\sum_ip_i=1\) で正規化されている）。\(B\) を部分トレースすると、 \(\{\ket i\}\) の直交性から交差項が消えて \[ \tr_B\ketbra\Psi\Psi = \sum_i p_i\ketbra{\psi_i}{\psi_i} = \rho, \] すなわち \(\ket\Psi\) は \(\rho\) の純粋化である。性質 4（§11.3.2）より \[ S(\rho) = S(\rho_B), \qquad \rho_B = \tr_A\ketbra\Psi\Psi = \sum_{i,j}\sqrt{p_ip_j}\,\braket{\psi_j}{\psi_i}\,\ketbra ij . \] ここで \(\rho_B\) に基底 \(\{\ket i\}\) への射影測定 \(\{P_i=\ketbra ii\}\) を施すと、 非対角成分が消えて \[ \rho_B' = \sum_i P_i\rho_BP_i = \sum_i p_i\ketbra ii \] となる（対角成分は \(\bra i\rho_B\ket i=p_i\braket{\psi_i}{\psi_i}=p_i\)）。 射影測定はエントロピーを増やす（§11.3.3）から \[ S(\rho) = S(\rho_B) \ \le\ S(\rho_B') = H(p). \]

ステップ2：一般の場合。 各 \(\rho_i\) をスペクトル分解する： \(\rho_i=\sum_j\lambda_i^{(j)}\ketbra{e_i^{(j)}}{e_i^{(j)}}\)。すると \[ \rho = \sum_i p_i\rho_i = \sum_{i,j} p_i\lambda_i^{(j)}\,\ketbra{e_i^{(j)}}{e_i^{(j)}} \] は、確率 \(\{p_i\lambda_i^{(j)}\}_{i,j}\) による純粋状態 \(\{\ket{e_i^{(j)}}\}\) の混合である。ステップ1をこのアンサンブルに適用して \[ S(\rho) \ \le\ H\bigl(\{p_i\lambda_i^{(j)}\}\bigr) = -\sum_{i,j}p_i\lambda_i^{(j)}\bigl(\log p_i+\log\lambda_i^{(j)}\bigr) = H(p) + \sum_i p_i\,S(\rho_i) \] （\(\sum_j\lambda_i^{(j)}=1\) を使って和を整理した。§11.3.2 性質 5 の計算と同一である）。

等号条件。台が互いに直交するなら、\(\rho\) の上の表示はそのまま スペクトル分解であり（異なる \(i\) のベクトルも直交するから）、 固有値が \(\{p_i\lambda_i^{(j)}\}\) と確定して等号が成り立つ ——これは結合エントロピー定理の計算そのものである。 逆に等号が成り立つとき台が直交することは、ステップ1の等号条件 （射影測定で \(\rho_B\) が不変、すなわち \(\rho_B\) が \(\{\ket i\}\) 基底で対角 \(\Leftrightarrow\) \(\sqrt{p_ip_j}\braket{\psi_j}{\psi_i}=0\)（\(i\ne j\)）、 すなわち混合される純粋状態が互いに直交）を ステップ2のアンサンブルに適用すれば従う。∎

凹性と合わせると、混合状態のエントロピーは \[ \sum_i p_iS(\rho_i) \ \le\ S\Bigl(\sum_i p_i\rho_i\Bigr) \ \le\ \sum_i p_iS(\rho_i) + H(p) \] と挟まれる。右の等号（直交する台）は「どの \(\rho_i\) だったかを測定で完全に識別できる」 場合であり、そのときラベルの不確かさ \(H(p)\) が丸ごとエントロピーに加算される。 逆に識別が不完全（台が重なる）だと加算は \(H(p)\) 未満に目減りする。 この「量子状態は識別できる分しか情報を運べない」という定量的教訓は、 Holevo 限界（第12章）の心臓部になる。

強劣加法性Strong subadditivity

3体系になると、エントロピーの不等式は一段深くなる。本節の主定理は次である。

定理（強劣加法性, strong subadditivity; SSA） 任意の3体状態 \(\rho_{ABC}\) に対して \[ S(A,B,C) + S(B) \ \le\ S(A,B) + S(B,C). \] 同値な形として、任意の \(\rho_{ABC}\) に対して \[ S(A) + S(B) \ \le\ S(A,C) + S(B,C) \] も成り立つ（同値性は証明の中で示す）。

形の覚え方：第1の形は「真ん中の系 \(B\) を共有する2つの塊 \(AB,BC\) に分けると、 全体＋共有部分のエントロピーは塊の和で抑えられる」。 条件付きエントロピー \(S(A|B)\equiv S(A,B)-S(B)\)、 量子相互情報量 \(I(A;B)=S(A)+S(B)-S(A,B)\) を使って書き直すと \[ S(A|B,C) \le S(A|B), \qquad I(A;B) \le I(A;B,C) \] とも読める（移項するだけである。§11.4.2 で改めて掲げる）。

なぜ古典のようには証明できないか 古典の対応物 \(H(X,Y,Z)+H(Y)\le H(X,Y)+H(Y,Z)\) は \(I(X;Z|Y)\ge0\)（§11.2.3）の書き換えにすぎず、 「\(y\) ごとに分解して各点で相互情報量が非負」という点ごとの議論で済んだ。 量子では \(B\) の値で条件付けた「\(y\) ごとの状態」への分解が一般には存在しない （\(\rho_{ABC}\) は \(B\) の基底について非対角成分を持つ）。 さらに量子の条件付きエントロピーは負になりうる： Bell 状態では \(S(A|B)=S(A,B)-S(B)=0-1=-1\)。 古典の直観（Venn 図の各領域が非負）はここで完全に破綻しており、 SSA が成り立つこと自体が非自明な定理である。 実際、その証明は長らく未解決で、1973年に Lieb と Ruskai によって初めて与えられた。 以下では原書に沿い、Lieb の定理を出発点とする証明を行間を埋めて再構成する。

§11.4.1 証明の構成

証明は3段のリレーである： (0) Lieb の定理（演算子の同時凹性。証明は付録A6） → (1) 条件付きエントロピーの凹性 → (2) 鍵補題 \(S(C|A)+S(C|B)\ge0\) → (3) 純粋化による SSA の導出。

ステップ0：Lieb の定理。

定理（Lieb, 1973） 任意の行列 \(X\) と \(0\le t\le1\) に対し、正半定値行列の組 \((A,B)\) の関数 \[ f(A,B) \equiv \tr\bigl(X^\dagger A^{t}\,X\,B^{1-t}\bigr) \] は \((A,B)\) について同時凹である（§11.3 冒頭の remark-box の意味で）。

この定理の証明は解析的でやや長く、本章の流れからは独立なので、 付録A6 に委ねる。 特別な場合 \(t=1/2,\ X=I\) は「\(\tr(\sqrt A\sqrt B)\) の同時凹性」で、 すでに忠実度の性質（第9章）の裏で働いていた種類の主張である。 以下で使うのは \(X=I\) の場合だけである。

ステップ1：条件付きエントロピーの凹性。

補題1（\(S(A|B)\) の凹性） \(S(A|B)=S(A,B)-S(B)\) は \(\rho_{AB}\) の凹関数である： \(\rho_{AB}=\sum_k q_k\,\rho_{AB}^{(k)}\) ならば \(S(A|B)_{\rho}\ \ge\ \sum_k q_k\,S(A|B)_{\rho^{(k)}}\)。
証明

\(0\le t\le 1\) に対して補間関数 \[ I_t(\rho_{AB}) \equiv \tr\Bigl(\rho_{AB}^{\,t}\,\bigl(I_A\otimes\rho_B\bigr)^{1-t}\Bigr), \qquad \rho_B = \tr_A\rho_{AB} \] を定義する（以下しばらく \(\rho_{AB}\) は正定値（フルランク）と仮定する。 一般の場合は \(\rho\to(1-\epsilon)\rho+\epsilon I/d\) と正則化して \(\epsilon\to0\) の連続極限を取ればよい）。

(i) \(I_t\) は \(\rho_{AB}\) の凹関数である。 Lieb の定理（\(X=I\)）より \((M,N)\mapsto\tr(M^tN^{1-t})\) は同時凹。 一方、\(\rho_{AB}\mapsto\bigl(\rho_{AB},\,I_A\otimes\tr_A\rho_{AB}\bigr)\) は 線形写像である。同時凹関数と線形写像の合成は凹だから、 \(I_t\) は \(\rho_{AB}\) について凹である。 （各引数ごとの凹性では足りず、同時凹性が本質的に必要な箇所がここである： 第2引数 \(I\otimes\rho_B\) が第1引数と連動して動くからである。）

(ii) \(t\to1\) の傾きが条件付きエントロピーを与える。 まず \(I_1=\tr\rho_{AB}=1\)（\(\rho\) によらない定数）。 正定値行列 \(M\) に対する微分公式 \(\frac{d}{dt}M^{\,t}=M^{\,t}\ln M\) を使うと \[ \frac{d}{dt}I_t = \tr\Bigl(\rho^{\,t}(\ln\rho)\,(I\otimes\rho_B)^{1-t}\Bigr) - \tr\Bigl(\rho^{\,t}\,(I\otimes\rho_B)^{1-t}\ln(I\otimes\rho_B)\Bigr) \] （\(\rho\equiv\rho_{AB}\) と略記。\((I\otimes\rho_B)^{1-t}\) と \(\ln(I\otimes\rho_B)\) は 可換なので順序の曖昧さはない）。\(t=1\) で評価すると \((I\otimes\rho_B)^{0}=I\) だから \[ \frac{d}{dt}I_t\Big|_{t=1} = \tr(\rho\ln\rho) - \tr\bigl(\rho\,(I\otimes\ln\rho_B)\bigr) = \bigl[-S(A,B) + S(B)\bigr]\ln 2 = -S(A|B)\,\ln 2 , \] ここで \(\ln(I\otimes\rho_B)=I\otimes\ln\rho_B\)、 \(\tr(\rho_{AB}(I\otimes\ln\rho_B))=\tr(\rho_B\ln\rho_B)\)（部分トレース）、 および底の変換 \(\tr(\rho\log\rho)=\tr(\rho\ln\rho)/\ln2\) を使った。

(iii) 凹性の受け渡し。 微分を左からの差分商の極限として書くと \[ S(A|B)\,\ln 2 = -\frac{d}{dt}I_t\Big|_{t=1} = \lim_{t\to1^-}\frac{I_t(\rho_{AB}) - 1}{1-t}. \] 各 \(t<1\) に対し、写像 \(\rho_{AB}\mapsto\bigl(I_t(\rho_{AB})-1\bigr)/(1-t)\) は 「凹関数から定数を引いて正数で割ったもの」なので凹である。 凹関数の各点収束極限は凹だから、\(S(A|B)\ln2\)、 したがって \(S(A|B)\) も \(\rho_{AB}\) の凹関数である。∎

凹性の意味を確認しておく：状態を混ぜたとき、「\(B\) を知った上での \(A\) の残り不確かさ」は 平均以上に増える。古典なら \(H(X|Y)=\sum_yp(y)H(X|Y=y)\) の凹性として初等的に示せるが、 量子では上のとおり Lieb の定理という重い機械が要る。

ステップ2：鍵補題。

補題2 任意の3体状態 \(\rho_{ABC}\) に対して \[ S(C|A) + S(C|B) \ \ge\ 0 . \] （各項は負になりうるのに、この組み合わせは常に非負、という主張である。）
証明

\(T(\rho_{ABC}) \equiv S(C|A)+S(C|B)\) と置き、2つの性質を示す。

(i) \(T\) は \(\rho_{ABC}\) の凹関数。 第1項 \(S(C|A)\) は \(\rho_{AC}=\tr_B\rho_{ABC}\) だけの凹関数（補題1）であり、 部分トレース \(\rho_{ABC}\mapsto\rho_{AC}\) は線形だから、 合成 \(\rho_{ABC}\mapsto S(C|A)\) は凹。第2項も同様。凹関数の和は凹である。

(ii) 純粋状態では \(T=0\)。 \(\rho_{ABC}=\ketbra\psi\psi\) が純粋なら、性質 4（§11.3.2）を分割 \((AC|B)\) と \((BC|A)\) に適用して \(S(A,C)=S(B)\)、\(S(B,C)=S(A)\)。よって \[ T = \bigl[S(A,C)-S(A)\bigr] + \bigl[S(B,C)-S(B)\bigr] = \bigl[S(B)-S(A)\bigr] + \bigl[S(A)-S(B)\bigr] = 0 . \]

仕上げに、任意の \(\rho_{ABC}\) を純粋状態に分解する： \(\rho_{ABC}=\sum_k q_k\ketbra{\psi_k}{\psi_k}\)（例えばスペクトル分解）。凹性 (i) と (ii) から \[ T(\rho_{ABC}) \ \ge\ \sum_k q_k\,T\bigl(\ketbra{\psi_k}{\psi_k}\bigr) = 0 . \] ∎

補題2を移項すると \(S(A)+S(B)\le S(A,C)+S(B,C)\)、 すなわち定理の第2の形はこの時点で証明済みである （\(S(C|A)+S(C|B) = S(A,C)+S(B,C)-S(A)-S(B)\) に注意）。

ステップ3：純粋化で第1の形を得る。

証明（SSA 第1形） 与えられた \(\rho_{ABC}\) に参照系 \(R\) を付けて純粋化する：\(ABCR\) が純粋。 すると性質 4 より \[ S(A,B,C) = S(R), \qquad S(A,B) = S(C,R). \] 示すべき不等式 \(S(A,B,C)+S(B)\le S(A,B)+S(B,C)\) は、これらを代入すると \[ S(R) + S(B) \ \le\ S(C,R) + S(B,C), \] すなわち \[ 0 \ \le\ \bigl[S(C,R)-S(R)\bigr] + \bigl[S(B,C)-S(B)\bigr] = S(C|R) + S(C|B) \] と同値になる。これは補題2を（4体状態 \(\rho_{BCR}=\tr_A\) に対し、 系の名前を \(A\to R\) と読み替えて）適用したものに他ならない。∎
証明の見取り図（何が効いたか）
  1. 非可換性の核心的困難は「\(\tr(M^tN^{1-t})\) の同時凹性」（Lieb）に集約され、そこだけが解析的に重い。
  2. Lieb から条件付きエントロピーの凹性へは、「\(t\to1\) の差分商」という補間トリックで渡る。 エントロピーは \(\tr\rho^t\) 型の量の \(t=1\) での微分係数として現れる、という視点は 他の場面（Rényi エントロピー、レプリカ法）でも有用である。
  3. 凹性は「純粋状態で成り立つ等式を混合状態の不等式に格上げする」ために使われた（補題2）。
  4. 最後は例によって純粋化がエントロピーを両替した。
なお、SSA の等号成立条件（\(B\) を挟んで \(A\) と \(C\) が「量子 Markov 連鎖」をなす、 という構造定理）はさらに後年の結果であり、本書の範囲を超えるので触れるにとどめる。

§11.4.2 初等的応用

SSA は量子情報理論の「万能ドライバー」である。よく使う帰結を証明付きで列挙する。

系1（条件付けはエントロピーを減らす） \[ S(A|B,C) \ \le\ S(A|B). \]
証明 定義を代入すると \(S(A|B,C)=S(A,B,C)-S(B,C)\)、\(S(A|B)=S(A,B)-S(B)\) なので、主張は \[ S(A,B,C)+S(B) \le S(A,B)+S(B,C) \] すなわち SSA そのものの書き換えである。∎
系2（系を捨てると相互情報量は増えない） \[ I(A;B) \ \le\ I(A;B,C). \]
証明 \[ I(A;B,C)-I(A;B) = \bigl[S(A)+S(B,C)-S(A,B,C)\bigr]-\bigl[S(A)+S(B)-S(A,B)\bigr] = S(B,C)+S(A,B)-S(A,B,C)-S(B) \ \ge\ 0 \] で、最後の不等号が SSA である。∎
系3（量子操作は相互情報量を増やさない） 系 \(AB\) の状態 \(\rho_{AB}\) に対し、\(B\) だけにトレース保存量子操作 \(\mathcal E\)（§8.2）を施して \(B'\) を得たとする（\(A\) には何もしない）。このとき \[ I(A;B') \ \le\ I(A;B). \]
証明

量子操作の環境モデル（§8.2.2）を使う：純粋状態 \(\ket0\) に初期化した環境 \(C\) を付け、 \(BC\) にユニタリ \(U\) を作用させ、最後に環境を捨てれば \(\mathcal E\) が実現できる。 この3段階で \(I(A;\cdot)\) を追跡する。

(1) 環境の付加：\(\rho_{ABC}=\rho_{AB}\otimes\ketbra00_C\) では、 純粋因子はエントロピーに寄与しない（§11.3.2 性質 5 で \(H=0\) の場合、あるいは 加法性）ので \(S(B,C)=S(B)\)、\(S(A,B,C)=S(A,B)\)。よって \(I(A;B,C)=I(A;B)\)：無相関な環境を付けても相互情報量は変わらない。

(2) \(BC\) 上のユニタリ：\(U_{BC}\) は \(\rho_A\) を変えず、 \(\rho_{BC}\) と \(\rho_{ABC}\) をユニタリ共役するだけなので、 ユニタリ不変性（§11.3.2 性質 3）より \(I(A;B,C)\) は不変。

(3) 環境を捨てる：系2より \(I(A;B')\le I(A;B',C')\)。

つなげると \[ I(A;B') \ \le\ I(A;B',C') \ = \ I(A;B,C) \ = \ I(A;B). \] ∎

系3は古典のデータ処理不等式（§11.2.4）の「片側版」の量子化と読める： \(B\) 側でどんな局所処理をしても、\(A\) との相関は増やせない。

系4（条件付きエントロピーの劣加法性） 4体状態 \(\rho_{ABCD}\) に対し \[ S(A,B\,|\,C,D) \ \le\ S(A|C) + S(B|D). \] また3体状態に対して \[ S(A,B\,|\,C) \ \le\ S(A|C) + S(B|C), \qquad S(A\,|\,B,C) \ \le\ S(A|B). \] （条件を付けても、劣加法性の形は保たれる。）
証明 第1式：SSA を2回使う。まず分割 \((A,\,C,\,BD)\)（真ん中が \(C\)）への SSA から \[ S(A,B,C,D) + S(C) \ \le\ S(A,C) + S(B,C,D), \] 次に分割 \((B,\,D,\,C)\)（真ん中が \(D\)）への SSA から \[ S(B,C,D) + S(D) \ \le\ S(B,D) + S(C,D). \] 辺々加えて \(S(B,C,D)\) を消去すると \[ S(A,B,C,D) + S(C) + S(D) \ \le\ S(A,C) + S(B,D) + S(C,D), \] 移項して \[ \underbrace{S(A,B,C,D)-S(C,D)}_{=\,S(A,B|C,D)} \ \le\ \underbrace{S(A,C)-S(C)}_{=\,S(A|C)} + \underbrace{S(B,D)-S(D)}_{=\,S(B|D)} . \] 第2式：分割 \((A,\,C,\,B)\) への SSA \(S(A,B,C)+S(C)\le S(A,C)+S(B,C)\) の両辺から \(2S(C)\) を引けばよい。第3式は系1である。∎
予告：量子データ処理不等式 古典のデータ処理不等式 \(H(X)\ge I(X;Y)\ge I(X;Z)\) の完全な量子版は第12章で扱う。 主役はコヒーレント情報 (coherent information) \[ I(A\rangle B) \equiv S(B) - S(A,B) = -S(A|B) \] ——まさに「条件付きエントロピーの負値」であり、これが正であることが 量子相関（エンタングルメント）の存在の証書になる。 量子操作の列 \(\rho\to\mathcal E_1(\rho)\to(\mathcal E_2\circ\mathcal E_1)(\rho)\) に沿って コヒーレント情報が単調に減少するという量子データ処理不等式が成り立ち、 その証明の要は本節の SSA（系1〜3の変形）である。 コヒーレント情報は量子チャネル容量（どれだけの量子ビットをノイズのあるチャネルで 送れるか）を支配する量であり、SSA が量子 Shannon 理論全体を支えていることが そこで明らかになる。
第11章のまとめ
  • Shannon エントロピー \(H(X)=-\sum p\log p\) は「驚き \(-\log p\) の期待値」であり、 データ圧縮の限界という操作的意味を持つ。規約 \(0\log0=0\) は連続極限による。
  • 相対エントロピー \(H(p\|q)\ge0\)（Gibbs の不等式）が古典不等式の生成源： \(H\le\log d\)、劣加法性、相互情報量の非負性が一斉に従う。 条件付きエントロピーは古典では非負で、連鎖律 \(H(X,Y)=H(Y)+H(X|Y)\) が成り立つ。
  • データ処理不等式：Markov 連鎖 \(X\to Y\to Z\) で \(I(X;Z)\le I(X;Y)\)。 失った情報は後処理で戻らない。
  • von Neumann エントロピー \(S(\rho)=-\tr\rho\log\rho\) は固有値分布の Shannon エントロピー。 純粋状態で 0、最大混合で \(\log d\)、ユニタリ不変。 量子相対エントロピーの非負性（Klein の不等式）が量子不等式の生成源になる。
  • 合成系が純粋なら \(S(A)=S(B)\)（Schmidt 分解）。Bell 状態では \(S(AB)=0\) なのに \(S(A)=1\)：「部分が全体より不確か」は量子固有で、\(S(A|B)<0\) が可能。
  • 非選択的射影測定はエントロピーを増やす。劣加法性 \(S(AB)\le S(A)+S(B)\) と 三角不等式 \(S(AB)\ge|S(A)-S(B)|\)（Araki–Lieb；純粋化で証明）が2体系の限界を与える。
  • 混合のエントロピーは \(\sum p_iS(\rho_i)\le S(\sum p_i\rho_i)\le\sum p_iS(\rho_i)+H(p)\) と挟まれる （下限＝凹性は補助系＋劣加法性、上限は純粋化＋測定エントロピー増大で証明。 上限の等号は台が直交するとき）。
  • 強劣加法性 \(S(ABC)+S(B)\le S(AB)+S(BC)\)： Lieb の定理 → 条件付きエントロピーの凹性 → 補題 \(S(C|A)+S(C|B)\ge0\) → 純粋化、 という段取りで証明される。帰結として、条件付けはエントロピーを減らし、 系を捨てても・量子操作を施しても相互情報量は増えず、 条件付きエントロピーも劣加法的。これらが第12章の量子 Shannon 理論の全基盤となる。
